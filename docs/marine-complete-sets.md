# 돌고래·꽃게·해파리 완성 착장

선택한 시안은 돌고래 1·2번, 꽃게 3·5번, 해파리 3·6번이다. 기본 캐릭터 6종에 각 20개 완성 착장을 제작했다. 기본 모습까지 총 126개 이미지다.

| 종류 | 선택 | 친구 | 공유 상품 |
| --- | --- | --- | --- |
| 돌고래 | 1 파랑 / 2 분홍 | 파도 / 로지 | 돌고래 착장 20개 |
| 꽃게 | 3 보라 / 5 노랑 | 라비 / 집콩 | 꽃게 착장 20개 |
| 해파리 | 3 보라 / 6 무지갯빛 | 루미 / 오로라 | 해파리 착장 20개 |

같은 종류의 두 친구는 상품 하나를 공유하며 실제 착용 이미지는 각각 다르다. 다른 종류의 옷은 미리보기·착용·서버 저장에서 거절한다. 각 카드는 옷과 액세서리 구성을 구분해서 표시하고, 고르면 모두 입은 이미지 한 장으로 바뀐다. 기본 모습 버튼으로 세트를 해제한다. 해마의 기존 구매·전환 동작을 그대로 사용한다.

돌고래는 몸통에 의상을 맞추고 지느러미·꼬리를 노출했다. 꽃게는 얼굴 아래 등딱지에 맞춘 옷을 사용하고 집게·다리를 유지했다. 해파리는 갓 아래에 걸치는 케이프·망토로 꾸미고 촉수를 유지했다. 독립된 모자·안경·옷 레이어는 추가하지 않았다.

내장 이미지 생성으로 제작한 원본 PNG 7장은 `public/my-space/marine/v1/sheets/`에 있다. `selected-base.png`는 선택한 기본형 6종이며, 나머지 6장은 캐릭터별 5열×4행 착장 시트다. 실제 화면은 `public/my-space/marine/v1/{pet}/{motif}.webp`의 768×768 투명 이미지를 사용한다. `bare.webp`는 기본형이다. 원본에서 붙어 있는 인접 캐릭터는 알파 영역과 칸 중심을 기준으로 분리했다.

- 정확한 프롬프트와 캐릭터별 원본 연결: [marine-complete-sets.json](./marine-complete-sets.json)
- 배포 이미지 126개의 해시·크기·원본 칸: `public/my-space/marine/v1/manifest.json`
- 상품·선택 번호·별명: `src/modules/my-space/marine.ts`

검증은 실제 React 컴포넌트의 정적 렌더링, 이미지 투명 배경과 여백, 구매 중복 차감 방지, 저장·다시 불러오기·동종 친구 전환·기본 모습 복귀, 종류 간 착용 거절을 포함한다. 구매 검사는 실제 서버 함수와 메모리 저장소를 사용하며 외부 서비스는 호출하지 않는다. 작품전시 기능은 변경하지 않는다.
