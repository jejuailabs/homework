# 도구 창 배치

- 도구별 작업 공간을 `src/lib/tool-window-layout.ts`에서 정합니다. 시계·주사위 같은 작은 조작 도구, 일반 수업 도구, 자리·교구 같은 넓은 작업 도구, 문서 편집 도구에 서로 다른 기본 크기를 사용합니다.
- 사진 글 정리는 최대 1440×960의 넓은 창으로 시작합니다. 문서 작업이 어려운 작은 화면과 휴대폰에서는 처음부터 최대화합니다. 판서와 함께캔버스도 최대화로 시작합니다.
- 내용이 늘어나면 남는 화면 범위까지 창 높이를 늘립니다. 사용자가 직접 크기를 조절한 뒤에는 자동으로 다시 키우지 않습니다. 이동·화면 크기 변경 시 창이 화면 밖으로 벗어나지 않게 보정합니다. 새 브라우저 창도 해당 도구의 기본 크기를 사용합니다.
- 창 제목을 한 줄로 압축하고 타이머·교구·자료 편집 화면의 큰 여백을 줄였습니다. 긴 목록·문서·부가 설정에는 필요한 스크롤을 유지합니다.
- 사진 글 정리는 실제 창 너비에 맞춰 반응합니다. 넓으면 사진과 텍스트를 나란히, 좁으면 ‘사진·읽기 / 원문·교정본’ 전환으로 표시합니다. 사진은 남은 공간에 맞추고 실행·복사·저장을 읽기 영역과 분리하여 긴 결과가 버튼을 밀어내지 않게 합니다.
- 이 변경은 창과 화면 배치에 한정됩니다. AI·Firebase 호출 방식·할당량·결제 설정·저장 형식은 변경하지 않습니다. 사진 처리 QA에는 로컬 모의 응답만 사용합니다.
