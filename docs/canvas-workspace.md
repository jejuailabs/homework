# 판서와 함께캔버스

## 사용하는 방법

- 색연필 메뉴는 판서로 통합했습니다. 판서의 펜 종류에서 펜·볼펜·색연필·마커·형광펜을 고릅니다. 색연필은 반복되는 안료 질감을 화면과 PNG에 동일하게 적용하며 마커는 일정한 굵기와 평평한 끝, 형광펜은 투명한 색을 사용합니다. 손가락·마우스는 움직임에 따른 굵기 변화, 펜 기기는 실제 압력 값을 사용합니다.
- 기존 `board`와 `pencils` 브라우저 저장 키는 보존합니다. 판서에서 “예전 색연필 그림 열기”로 기존 그림을 열 수 있습니다. 옛 색연필 주소도 판서로 연결하며 해당 문서를 엽니다. 합치면서 어느 문서도 다른 문서로 덮어쓰지 않습니다.
- 함께캔버스에서 학급·참여 학생을 선택하고 활동을 시작합니다. 선생님의 “활동판”에서 모둠 탐구, 알고/궁금/배운 것, 이야기 만들기, 비교 활동을 추가할 수 있습니다. 기존 내용은 유지하고 옆에 새 구역과 메모를 추가합니다.
- 누구나 참여 권한이 있는 캔버스의 빈 곳에 메모·글·사진·도형·화살표를 놓고 이동·확대·편집할 수 있습니다. 사진은 파일 선택, 끌어놓기, 클립보드로 추가합니다. 인터넷 링크는 실행되는 임베드가 아닌 텍스트로 붙여넣습니다. 텍스트의 더블클릭 편집, 부분 서식, 한글 입력은 기존 동작을 유지합니다.
- 마우스 휠/트랙패드로 이동, Ctrl/⌘+휠로 포인터를 기준으로 확대, 두 손가락으로 이동·확대합니다. 스페이스바 또는 손 도구로도 이동할 수 있습니다. 전체 보기·선택 보기·100%·미니맵·활동 구역 목록·글 검색으로 위치를 찾습니다.
- 친구 찾기는 기존 참여자 커서 위치를 찾아가거나 선택한 참여자의 커서 위치를 따라갑니다. 다른 사람의 화면을 강제로 이동시키지 않습니다. 내 화면을 조작하면 따라가기를 끝냅니다. 카메라는 내 기기에서만 바뀌고 문서 변경으로 동기화하지 않습니다.
- 함께캔버스 창은 처음부터 브라우저 영역 전체를 채웁니다. 창의 최대화 버튼 또는 제목 줄 두 번 클릭으로 이전 크기로 전환할 수 있습니다. 수업 이름·연결 상태·참여자·수업 설정은 한 줄에 표시하고, 세로 도구 모음·서식·색상·확대 도구는 작업판 위에 띄웁니다. 글을 편집하거나 설정을 열어도 캔버스 높이가 줄어들지 않습니다.
- 객체 작업·겹친 객체 선택·격자·손가락 그리기·저장·인쇄·불러오기는 작업판 왼쪽 아래 “메뉴”에서 사용합니다. 편집기 자체의 전체 화면도 지원하며 브라우저 전체 화면 API를 사용할 수 없으면 화면을 채우는 배치로 표시합니다. 전체 화면에서도 같은 편집기를 유지하므로 편집 내용과 실행 취소 이력이 이어집니다.
- 선생님의 학생 편집 잠금·학생 QR·수정 이력·장면 저장·과거 버전 복원은 “수업 설정·저장·기록”에서 사용합니다. 기존 로그인·학급/모둠 참여 권한과 서버 검사는 유지합니다.
- PNG/인쇄는 넓은 보드의 전체 내용을 포함합니다. 내보내기 이미지는 8192px 변, 약 1600만 화소 이내로 축소해 브라우저 메모리를 제한합니다. 편집 원본에는 실제 좌표·텍스트·새 도형과 메모를 유지합니다.

## 구현과 운영 범위

- 기존 Yjs 문서·Firebase API/저장소와 perfect-freehand를 확장했습니다. 새 유료 SDK·AI API·구독·컬렉션·백그라운드 작업은 추가하지 않습니다. 기존 동기화·참여자 전송·체크포인트 주기도 바꾸지 않습니다.
- 고정된 1200×720 종이 대신 카메라가 보이는 세계 좌표를 SVG viewBox로 표시합니다. 화면 밖 객체는 렌더링을 생략합니다. 실용적인 수치 안전 한계는 좌표 ±1,000,000, 객체 크기 100,000, 확대 0.01%~12,800%입니다. 기존 문서는 좌표 변환 없이 읽습니다.
- “무한”은 종이 경계 없이 작업 공간을 이동한다는 뜻입니다. 서버 저장 용량은 무제한이 아닙니다. 기존 400객체, 캔버스당 이미지 100장/20MiB, 이미지별 업로드 크기 및 기존 변경량 제한을 유지합니다. 기존 데이터 마이그레이션이나 삭제는 없습니다.
- 모의 검증은 실제 DB·Storage·유료 API를 호출하지 않습니다. 운영에서 사진과 편집이 늘면 기존 Firebase의 읽기/쓰기·저장·네트워크 비용이 늘 수 있습니다. 남은 무료 할당과 지역별 단가는 별도로 확인해야 하며, 해당 유료 운영 범위 승인 후 GitHub main 푸시로 자동 배포합니다.

## 참고한 사용 흐름

- [tldraw camera](https://tldraw.dev/sdk-features/camera): 카메라와 화면/문서 좌표, 포인터 기준 줌, 전체/선택 맞춤.
- [Miro sticky notes](https://help.miro.com/hc/en-us/articles/360017572054-Sticky-notes): 생각을 담는 색 메모와 보드 위 배치.
- [Padlet Sandbox](https://padlet.blog/sandbox-allowed-tools/): 수업 목적을 중심으로 협업 도구를 구성하는 흐름.

위 도구의 SDK나 외부 계정을 연결하지 않았습니다. 비용 기준 참고: [Firestore](https://firebase.google.com/docs/firestore/pricing), [Firebase Storage](https://firebase.google.com/pricing).
