# 베리 사용 안내 (선생님용)

베리는 모두의 교실 안에서 선생님 일을 대신 찾아보고, 말로 시킨 일을 확인 카드로 준비해 주는 업무 비서입니다.
화면 오른쪽 아래 🍇 버튼을 누르면 열립니다. 채팅창의 **할 수 있는 일** 버튼을 누르거나, 평소 말투로 시키면 됩니다.

> 이 문서는 채팅창 버튼 목록(`src/modules/berry-panel/abilities.ts`)과 같은 내용을 담고 있습니다. 기능이 늘면 둘을 함께 고칩니다.

---

## 1. 베리가 일하는 방식

| 구분 | 어떻게 동작하나요 |
|---|---|
| 찾아보기(읽기) | 묻는 즉시 답합니다. 숙제·제출·전시·보드·퀴즈·보말·일정 등 모두의 교실의 현재 기록을 그 자리에서 읽습니다. |
| 시키기(쓰기) | 베리는 바로 바꾸지 않고 **확인 카드**를 띄웁니다. 카드의 [저장]을 눌러야 반영되고, [취소]하면 아무것도 바뀌지 않습니다. 카드는 10분 동안 유효합니다. |
| 위험한 일 | 지우기·차감·학생 코드 재발급처럼 되돌리기 어려운 일은 **빨간 카드**로 뜨고, [실행]을 **두 번** 눌러야 합니다. |
| 바로가기 | 답에 숙제·전시실·보드가 나오면 아래에 **바로 열기 버튼**이 붙습니다. |

### 확인 카드에 표시되는 것
- **대상**: 어느 학급의 어떤 숙제·전시실·보드인지
- **바꿀 내용**: `테마: 아늑한 → 숲`처럼 지금 값과 바뀔 값
- **알림**: "학생 화면에 바로 보여요", "외부에 공개돼요", "보말 10점이 지급돼요"처럼 결과로 생기는 일

## 2. 베리가 볼 수 있는 것과 볼 수 없는 것

| 볼 수 있음 | 볼 수 없음 |
|---|---|
| 학급·명단(학생은 "학생 07"처럼 가명) | 학생 실명(선생님이 따로 허락한 경우만 선생님 화면에서 실명으로 바뀜) |
| 숙제·제출 집계·미제출·검사 대기 | 학생 비밀 일기 본문 (공유 건수만) |
| 전시실·작품 목록·승인 대기 | 학생 사진·영상·음성 원본 |
| 참여보드·게시물 제목·승인 대기 | 위치 정보 |
| 퀴즈·복습·말놀이터·보말·투표·캔버스 현황, 카드놀이 진도·안 끝낸 학생(가명)·많이 틀린 단어·반 평균 숙련도·날짜 복습이 남은 학생 수 | 교무수첩의 상담·건강·가정 기록 |
| 업무 공간(일정·시간표·수업 일지·폴더), 교무수첩(민감 기록 제외) | 다른 선생님의 학급 |

점수·순위는 모두의 교실 기록을 그대로 전할 뿐, 베리가 새로 평가하지 않습니다.

## 3. 연결과 권한

처음 한 번 **모두의 교실 연결하기**를 누르고 동의 화면에서 허락합니다.

| 권한 | 내용 | 기본 |
|---|---|---|
| 학급·숙제·업무 공간·알림·교실 메뉴 읽기 | 위 표의 "볼 수 있음" | 켜짐 |
| 교무수첩 읽기 | 민감 기록 제외 | 선택 |
| 학생 실명 | 선생님 화면에서만 실명 표시 | 선택 |
| 일정·업무 공간·교무수첩 쓰기 | 확인 카드로 저장 | 선택 |
| 교실 쓰기 | 숙제·전시실·보드·퀴즈·복습·말놀이터·보말·카드놀이 배부·수업 도구·학급 관리, 확인 카드로 저장 | 선택 |

- 2026-11-02 이전에 연결한 선생님은 교실 쓰기 권한이 없습니다. 채팅창에서 연결을 해제한 뒤 다시 연결하면 생깁니다.
- 연결은 마이페이지 > 연결에서 언제든 끊을 수 있습니다.

## 4. 할 수 있는 일 (버튼 목록)

✏️ 표시는 확인 카드로 저장되는 일, ⚠️ 표시는 두 번 눌러야 하는 위험한 일입니다. `[빈칸]`을 채워서 보내면 됩니다.

### ☀️ 지금 현황
- 지금 챙길 것 · 오늘 일정·수업 · 승인 기다리는 것 · 저장 공간

### 📚 숙제
- 이번 주 마감 숙제 · 안 낸 학생
- ✏️ 숙제 내기 — `[학급]에 [숙제 제목] 숙제 내 줘. 제출은 [사진/글/동영상], 마감은 [날짜]` (전시실·보드 자동 연동도 함께 켤 수 있음)
- ✏️ 마감 바꾸기, 제목·설명 고치기
- ✏️ 검사 완료 한꺼번에 — 검사 완료 1회마다 보말 10점이 지급됩니다
- ✏️ 다시 하기 요청(피드백 포함)
- ✏️ 숙제 숨기기·다시 표시

### 🖼️ 작품전시
- ✏️ 전시실 열기 · 대기 작품 모두 승인
- ✏️ 테마 바꾸기(아늑한·숲·하늘·바다) — 전시실 "배경"은 테마로 바뀝니다
- ✏️ 전시 준비·열기·마감, QR 공개 켜기·끄기(외부 공개), 댓글·학생 업로드 켜기·끄기
- ✏️ 도슨트 녹음·방명록·아트북 켜기·끄기
- ✏️ 작품 제목·설명·날짜 고치기, 작품 다시 하기(피드백), 작품 날짜 일괄 변경
- ⚠️ 전시실 삭제(작품 파일까지 모두 지워짐)
- 지난 전시 찾기(주제 태그·기간·학급)

### 📌 참여보드
- ✏️ 보드 열기 · 대기 글 모두 공개
- ✏️ 보드 설정 — 배치, 테마, 익명, 승인제, 댓글·반응, 열기·잠그기·보관
- ✏️ 선생님 글 올리기, 글 숨기기·고정
- ✏️ 공개 링크 만들기(외부 공개) · ⚠️ 공개 링크 다시 만들기(이전 링크는 끊김)

### ✏️ Quiz·복습
- 오늘 퀴즈 현황
- ✏️ 오늘·내일 퀴즈 범위 정하기(영어·수학)
- ✏️ 복습 배포 · 숨기기 · 다시 보이기, 복습 보상 켜기·끄기
- ⚠️ 복습 초안 삭제

### 🎯 보말·말놀이터
- 보말 순위 · 말놀이터 순위
- ✏️ 보말 주기(사유 필수)
- ⚠️ 보말 빼기(사유 필수)
- ✏️ 말놀이터 켜기·끄기, 대결·순위·보상 설정, 반 문제 추가

### 🧰 수업 도구
- ✏️ 투표 만들기·마감
- ✏️ 캔버스 만들기·잠그기·보관
- 카드 세트 진도, 안 끝낸 학생(가명), 지각 학생 수, 많이 틀린 단어
- ✏️ 카드 세트 배부(필수 학습·마감·마감 후 처리·테스트 형식과 제한 시간 포함)·배부 멈추기·다시 열기. 세트 만들기와 고치기, 이미 배부한 세트의 설정 수정은 카드놀이 화면에서 합니다. 리스트·카드·시험지·답지·빈칸 시험지·쓰기 연습·사선지 PDF도 세트 화면의 [인쇄] 버튼에서, 오답노트·성적표 PDF는 학습 리포트의 [인쇄] 버튼에서 직접 내려받습니다. 베리가 만들어 주지 않으며, 학생 이름이 들어가는 오답노트·성적표는 선생님 기기에서만 만들어집니다. 세트 편집 화면의 '가져오기·AI 초안'(단어 목록·단어장 글·단어장 사진·영어 본문에서 단어 뽑기·주제로 만들기 AI 초안, CSV·엑셀(.xlsx) 가져오기, 내 다른 세트 합치기)도 선생님이 직접 씁니다. 베리가 대신 만들거나 사진·파일을 받아 읽지는 않으며, 올린 사진은 저장되지 않아 베리도 알 수 없습니다. 실시간 카드 팀전도 세트 화면의 [카드 팀전] 버튼에서 선생님이 직접 엽니다. 베리는 진행 중인 방이 어떤 세트인지 알려 줄 수 있지만 대신 열거나 진행하지는 않습니다. 같은 창에서 다른 반을 함께 고르면 반대항전(반마다 한 팀, 반 평균 점수)으로 열리고, 베리는 진행 중인 반대항전의 반 이름만 알려 줍니다. 답하는 방식을 '먼저 쓰기'로 고르면 학생이 답을 직접 쓰고 가장 먼저 맞힌 학생만 점수를 받습니다(베리는 그런 방인지만 압니다).
- 끊어읽기: 선생님이 세트 편집에서 문장 카드마다 끊는 자리를 표시하면, 학생은 세트 화면의 [끊어읽기]에서 조각마다 끊어 읽고 섞인 조각을 맞춥니다. 연습이라 기록하지 않아 베리도 알 수 없고, 베리가 끊는 자리를 대신 정하지 않습니다.
- 연습문제 세트(객관식·O/X·객관식 빈칸·주관식·주관식 빈칸)는 세트 만들기에서 유형을 '연습문제'로 골라 선생님이 직접 만듭니다. 필수 학습 없이 배부되고 학생은 [연습문제 풀기](기록 없음)와 테스트로 공부합니다. 베리는 목록에서 연습문제 세트(drill: true)를 구분하고 테스트 진도를 다른 세트처럼 읽으며, 문항을 대신 만들지 않습니다. 베리는 세트마다 반 평균 숙련도(%)와 오늘 날짜 복습이 남은 학생 수·카드 수를 알려 줍니다. 학생 이름은 내보내지 않고, 학생별 숙련도와 '아직 숙련 안 된 카드'는 학습 리포트 화면에서 봅니다. 날짜 복습과 누적 오답 복습은 학생이 카드놀이 화면에서 직접 합니다.
- 교실 화면(전자칠판에 카드를 크게 띄워 넘기기·자동 넘김·소리 듣기)과 지명 퀴즈(학생을 뽑아 묻고 맞음·틀림으로 득점·서바이벌)는 세트 화면의 [교실 화면]·[지명 퀴즈] 버튼에서 선생님이 직접 엽니다. 베리가 대신 열지 않으며, 지명 퀴즈 결과는 저장하지 않아 베리도 알 수 없습니다.
- 우리 반 학습 기본값(세트 유형별 필수 학습 %, 읽어 주기 속도, 테스트·마감 후 처리)과 차시 메모·순서(줄 사이 메모, 순서, 강조, 학생에게 숨기기)는 [우리 반 세트]에서 선생님이 직접 정합니다. 베리는 바꾸지 않습니다. 베리로 배부할 때 말하지 않은 값은 그 반의 기본값으로 채워 확인 카드에 보여 주고, 세트 목록은 선생님이 정한 순서와 숨긴 줄·메모(학생 이름은 가림)로 읽습니다.
- 복습 게임(짝 맞추기·단어 비·문장 퍼즐)은 학생이 세트 화면의 [복습 게임]에서 혼자 합니다. 베리는 세트마다 게임별로 기록이 있는 학생 수만 알려 줍니다. 게임 점수·순위·학생 이름은 전하지 않으며, 게임 점수는 학습량·테스트 점수·숙련도와 별개입니다. 학생 화면의 '우리 반 순위'는 말놀이터 설정의 '순위 보이기'를 끄면 숨겨집니다.
- 학부모 링크(학생 한 명의 세트 학습만 보이는 읽기 전용 링크)와 카드놀이 보말(필수 학습 첫 완료 5개·테스트 목표 첫 달성 10개, 우리 반 학습 기본값 안의 스위치)은 선생님이 화면에서 직접 합니다. 베리는 세트마다 열린 링크 수·열린 적 있는 링크 수와 보말을 받은 학생 수만 알려 주고, 링크 주소·이름은 전하지 않습니다.
- 다른 반으로 옮기기(학기말 이월: 세트·학습 기본값·차시 메모를 다른 반에 배부하고, 이은 학생의 숙련도·복습 날짜·별표·최근 오답을 새 반으로 잇기)는 [우리 반 세트]의 [다른 반으로 옮기기]에서 선생님이 직접 합니다. 베리는 옮겨 온 배부에 원래 반 이름만 알려 줍니다. 같은 창의 '새 반 만들기(클래스 복제)'와 [우리 반 세트]의 [학습 일정](세트마다 학습할 날 정하기)도 선생님이 직접 합니다. 베리는 세트마다 학습할 날(plan_date)을 읽어 알려 줄 수 있습니다.
- 동료 공유(폴더를 동료 선생님 Google 이메일로 공유, 세트마다 공개·복제 허용, [공유받은 세트]에서 찾기·미리보기·내 세트로 복사)는 카드놀이 화면에서 선생님이 직접 합니다. 베리는 공유한 폴더 수·동료 수·공유한 세트 수·복사해 온 세트 수만 알려 줍니다. 동료 이메일·이름과 동료가 만든 세트 내용은 베리로 내보내지 않습니다(동료가 선생님 화면에 공유한 자료라서).
- 세트마다 학생 한 명이 다 하는 데 드는 예상 분(`minutes`: 필수 학습량 × 암기 4초·리콜 6초·스펠 10초 + 테스트 문항 × 15초, 어림)을 알려 줍니다. 학생별 남은 시간·오늘 많아요 안내·소리 설정·테스트 중 학습 대기는 학생 화면에만 있습니다.

## 5. 채팅으로 하지 않는 일

| 일 | 이유 |
|---|---|
| 사진·영상·파일 올리기 | 채팅창에 파일 첨부 기능이 아직 없습니다. 해당 메뉴 화면에서 올려 주세요. |
| 실시간 진행(말놀이터 라이브 방, 캔버스 함께 그리기) | 화면에서 바로 조작해야 하는 일입니다. |
| 관리자 기능, 학생 비밀 일기 | 베리에게 열지 않습니다. |
| 교무수첩 기록 고치기·지우기 | 교무수첩 잠금을 푼 화면에서만 할 수 있습니다. |

## 6. 잘 쓰는 요령

- **한 번에 여러 가지**: "3-2 전시실 숲 테마로 바꾸고 QR 공개 켜 줘" → 카드 하나에 두 가지가 같이 뜹니다.
- **이름으로 부르기**: 숙제·전시실·보드는 이름 일부만 말해도 찾습니다. 비슷한 이름이 여럿이면 베리가 되묻습니다.
- **카드부터 확인**: 저장 전에 대상과 바꿀 내용을 꼭 확인하세요. 틀리면 [취소] 후 다시 말하면 됩니다.
- **버튼으로 시작**: 채팅 중에도 위쪽 **메뉴** 탭이나 입력창 왼쪽 ✨ 버튼으로 처음 화면의 버튼을 쓸 수 있습니다. 대화는 그대로 남고, 버튼을 누르면 같은 대화에 이어집니다.
- **자물쇠 버튼**: 지금 연결에 없는 권한이 필요한 버튼입니다. 안내의 **다시 연결**을 누르고 연결 화면에서 쓰기 항목까지 선택하면 풀립니다. 새 권한은 다시 연결해야만 추가되고, 다른 선생님의 연결에는 영향이 없습니다.
- **꺼진 메뉴**: 교무수첩처럼 아직 열리지 않았거나 꺼져 있는 메뉴의 버튼은 목록에 나오지 않습니다.
