# 해솔·별몽 완성 착장

해마는 캐릭터별 PNG 시트 한 장에 옷과 액세서리를 모두 입은 20가지 모습을 생성하고, 각 모습을 투명 WebP로 잘라 사용한다. 기본 모습을 포함하면 캐릭터당 21종이다. 화면에는 캐릭터 이미지 한 장만 표시한다.

- 원본: `public/my-space/seahorse/v2/sheets/animal-seahorse-{butter,lilac}.png`
- 배치: 5열 × 4행, 왼쪽 위부터 행 우선 순서. 인접한 행 사이 여백이 좁으므로 등분한 사각형을 그대로 자르지 않고 연결된 캐릭터 영역을 추출했다.
- 배포 이미지: `public/my-space/seahorse/v2/animal-seahorse-{butter,lilac}/{motif}.webp` (768 × 768, 투명 배경)
- 기본 모습: 같은 폴더의 `bare.webp`
- 생성 방식·제작 사양·20개 착장 구성: [seahorse-complete-sets.json](./seahorse-complete-sets.json)
- 파일 크기·해시·원본 칸 번호: `public/my-space/seahorse/v2/manifest.json`

상점·구매 확인창·내 친구 보관함에서 옷과 액세서리 구성은 별도 항목으로 보여준다. 선택·구매 단위는 완성 착장 세트 하나다. 같은 세트를 해솔과 별몽이 공유하며, 다른 캐릭터에게는 적용하지 않는다. 배경·테두리는 기존 공용 꾸미기를 사용한다.

기존 분리형 해마 옷·장식 ID는 영수증과 보유 내역을 위해 보존하되 새 구매와 개별 착용은 막는다. 기존 구매자는 대응하는 세트를 추가 보말 없이 사용할 수 있다. 옛 옷은 멜빵→소풍, 잠옷→꿈나라, 세일러→선장, 니트→겨울에 연결한다. 장식은 안경→소풍, 물안경→탐험대, 방울모자·목도리→겨울, 수면모자→꿈나라, 리본·목걸이→리본 요정, 선원 모자→선장에 연결한다. 보유 내역과 잔액은 삭제하지 않는다.

독립 장식 합성용 해마 컴포넌트·좌표·스타일은 제거했다. 화이트니 등 기존 캐릭터의 표현 방식과 작품전시 기능은 변경하지 않는다.

검증은 전체 테스트, TypeScript, 실제 React 컴포넌트의 정적 렌더링, 42개 이미지의 투명 배경·여백·해시 검사로 수행한다. 구매·저장·재접속 검증은 실제 서버 함수와 메모리 저장소를 사용하며 외부 서비스는 호출하지 않는다.
