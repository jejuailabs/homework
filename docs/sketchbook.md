# 스케치북

## 사용하는 방법

- 선생님 도구 모음의 "판서·자료"에서 "스케치북"을 엽니다. 창은 판서처럼 화면 가득 시작합니다. `TOOLS_DISABLED=sketchbook`으로 끌 수 있고, 꺼도 기기에 저장된 그림은 지우지 않습니다.
- 왼쪽 레일에서 용도 묶음을 고르면 그 묶음의 붓이 펼쳐집니다. 그리기(연필·색연필·사인펜·마커), 칠하기(크레파스·수채 물감·물감 붓·채우기 통), 꾸미기(도형·거울 그리기), 고치기(지우개·문지르기·색 고르기)입니다. 레일 아래 "옮기기"는 손 도구입니다.
- 고른 붓의 굵기·불투명도·질감은 레일 옆 작은 설정 카드에서 바꿉니다. 카드 아래 물감 접시에는 지금 색과 최근 쓴 색 8개가 있고, `+`로 색 섞기(색상 고리·밝기 네모·기본 14색·색 번호)를 엽니다. 스포이트 버튼은 그림과 불러온 사진 어디서든 색을 가져옵니다. 커서 위치의 원은 지금 화면 배율에서의 실제 붓 굵기입니다.
- "이미지 불러오기"에서 파일 고르기·카메라 촬영을 쓰고, 창에 끌어놓거나 붙여넣어도 됩니다. 불러올 때 두 가지 중 고릅니다.
  - 도안으로 쓰기: 밝은 종이를 투명하게 하고 선만 남겨 맨 위 "선" 레이어에 놓은 뒤 잠급니다. "선으로 남길 진하기" 슬라이더로 종이 그림자와 끊긴 선 사이를 맞추고, 선을 검은색으로 맞출 수 있습니다. 놓으면 채우기 통과 "칠하기" 레이어가 자동으로 선택됩니다.
  - 사진으로 깔기: 맨 아래 "사진" 레이어에 깔고 잠급니다. "흐리게 깔기"는 따라 그리기용으로 불투명도를 45%로 둡니다.
  - 두 방법 모두 왼쪽·오른쪽 회전과 끌어서 자르기를 제공합니다. 기울기 보정은 하지 않습니다.
- 채우기 통은 선 레이어에 그림이 있으면 그 선을 경계로, 없으면 보이는 그림의 색 경계를 기준으로 칠합니다(Procreate의 참조 레이어 방식). 비슷한 색까지(허용 범위), 틈 메우기(0~8px, 그보다 좁은 틈은 닫힌 것으로 봄), 선 밑까지 칠하기(0~3px, 흰 테두리 방지)를 조절합니다. 선 위를 누르면 칠하지 않고 안내합니다.
- "선 안에만 칠하기"를 켜면 붓을 처음 댄 칸 밖으로 크레파스·색연필·물감이 나가지 않습니다(색칠공부 모드). 칸 계산은 백그라운드에서 하므로 빠르게 여러 번 그어도 획이 사라지지 않고 순서대로 반영됩니다.
- 레이어는 최대 5개입니다. 기본은 아래부터 사진·칠하기·그리기·선이며, 보이기·잠금·순서·불투명도·비우기와 그림 레이어 추가가 있습니다. "도구에 맞춰 자동으로 고르기"가 켜져 있으면 칠하기 묶음은 칠하기 레이어, 그리기·꾸미기 묶음은 그리기 레이어에 그립니다. 레이어를 직접 고르면 자동 고르기가 꺼집니다.
- 더 보기(⋯) 메뉴: 새 스케치북·종이(흰 도화지·미색·크라프트지·검은 종이·모눈 / 가로 A4·세로 A4·정사각형), 그림 파일(PNG) 저장, 인쇄, 편집 원본 내려받기·열기, 간단하게 보기, 펜으로만 그리기, 전체 화면.
  - 간단하게 보기: 레이어 버튼과 질감·채우기 세부 슬라이더를 숨기고 레이어를 자동으로 고릅니다(저학년 시범용).
  - 펜으로만 그리기: 펜 입력이 한 번 감지되면 손가락은 그리지 않고 화면 이동·확대에만 씁니다(손바닥 무시).
- 화면 이동·확대: 두 손가락(이동·확대·회전, 거의 똑바르면 0°로 맞춤), 손 도구, 스페이스바+끌기, 휠(이동)·Ctrl/⌘+휠(포인터 기준 확대), 오른쪽 아래 배율 버튼(누르면 종이 전체 보기). 창 크기가 바뀌면 "전체 보기" 상태일 때만 다시 맞춥니다.
- 단축키: Ctrl/⌘+Z 실행 취소, Ctrl/⌘+Shift+Z 또는 Ctrl/⌘+Y 다시 실행, `[` `]` 굵기, `0` 전체 보기, Esc 메뉴 닫기.

## 구현과 운영 범위

- 코드는 `src/modules/sketchbook/`에 있습니다. 등록은 `tool-catalog.ts`(`kind:'sketchbook'`), `tool-runner.tsx`(`ssr:false` 지연 로딩), `tool-window-layout.ts`(최대화 시작), `tools-hub.tsx`(아이콘)뿐입니다. 판서(`board`)·함께캔버스(`canvas`)의 코드와 저장 키는 바꾸지 않았습니다.
- `raster.ts`·`view.ts`·`document.ts`는 DOM에 의존하지 않는 순수 함수입니다. 채우기 경계·허용 오차·틈 메우기·선 밑 확장, 선화 추출 임계값, 실행 취소 패치 복원, 기록 한도, 크기 한도, 대칭·도형·카메라 계산을 `npm test`에서 검사합니다.
- `engine.ts`는 레이어마다 canvas 하나를 두는 래스터 엔진입니다. 붓은 점을 일정 간격으로 찍는 스탬프 방식이고, 크레파스·색연필·연필의 질감과 종이 결은 시드가 고정된 자체 생성 노이즈 타일입니다(외부 에셋 없음). 수채는 가장자리가 진한 번짐 스탬프를 곱하기 합성, 마커는 납작한 촉을 곱하기 합성, 물감 붓은 획마다 정해지는 붓털 배열로 그립니다.
- 채우기와 "선 안에만 칠하기"의 칸 계산은 Web Worker(`fill-worker.ts`)에서 합니다. Worker를 만들 수 없거나 15초 안에 답하지 않으면 같은 함수를 페이지에서 실행합니다.
- 실행 취소는 명령 재생 대신 바뀐 영역의 이전 픽셀(패치)을 저장해 맞바꾸는 방식입니다. 붓 무작위성 때문에 재생 결과가 달라지는 문제가 없고, 큰 캔버스에서도 되돌리기가 즉시 끝납니다. 최대 120단계, 192MiB 안에서 유지하며 넘으면 오래된 단계부터 버리되 50단계는 384MiB까지 지킵니다. 레이어 추가·삭제·순서 변경은 되돌리기 대상이 아닙니다. 새로고침하면 그림은 복원되지만 되돌리기 기록은 비워집니다.
- 한도: 캔버스 한 변 2,400px, 레이어 5개, 불러온 이미지 긴 변 2,400px(원본 5천만 화소 초과는 거절), 편집 원본 파일 120MB. 기본 종이는 A4 150dpi(1754×1240)입니다.
- 이미지를 불러오면 EXIF 회전만 반영해 픽셀을 다시 그리므로 위치·기기 정보는 남지 않습니다. 원본 파일은 저장하지 않습니다.
- 저장은 기기 안 IndexedDB(`ourclass-sketchbook` DB, 키 `sketchbook:{uid}:{classId}[:창 번호]`)에만 합니다. 변경 후 약 1.2초 뒤 레이어별 PNG와 설정을 저장하고 상단에 상태를 표시합니다. 도구 창을 닫으면 기다리던 저장을 바로 실행합니다. 브라우저 새로고침·탭 닫기는 페이지가 내려가는 중이라 "곧 저장해요" 상태의 마지막 변경이 남지 않을 수 있습니다. 붓 설정·최근 색 같은 작은 값은 localStorage에 둡니다. 서버·Firebase·AI 호출이 없어 운영 비용 변화가 없습니다. 다른 기기와는 동기화되지 않으므로 옮길 때는 편집 원본(.sketchbook.json, 레이어 PNG 포함)을 내려받아 엽니다.
- 새 그림 라이브러리·유료 SDK를 추가하지 않았습니다.

## 하지 않은 것 (다음 단계)

- 수업 모드(학생 참여·모아보기·시범 화면 공유), 전시실·작품집 제출, 오늘의 도안 지정은 2단계입니다(문서 `SKETCHBOOK_TOOL_PREBRIEF.md` P2). Firebase 비용 승인 후 별도로 진행합니다.
- 기본 도안 갤러리는 넣지 않았습니다(선생님이 불러온 이미지만 사용).
- P1 중 글자, 도형 보정(QuickShape), 무늬 롤러·스탬프, 타임랩스 재생은 아직 없습니다.
- 펜 압력은 Pointer Events의 `pressure`로 굵기에 반영하지만 실제 펜 기기에서는 확인하지 못했습니다.

## 참고한 사용 흐름

- [Procreate Layer options](https://help.procreate.com/procreate/handbook/layers/layers-options): 참조 레이어를 경계로 채우기, 알파 잠금 개념 → 선 레이어 기준 채우기와 "선 안에만 칠하기".
- [Procreate Symmetry guide](https://help.procreate.com/procreate/handbook/guides/guides-symmetry): 좌우·4방향·방사 대칭 → 거울 그리기.
- [Procreate Layer mask](https://help.procreate.com/procreate/handbook/layers/layers-mask): 칠 영역을 마스크로 제한하는 흐름.
- [Tux Paint 설명서](https://tuxpaint.org/docs/en/html/README.html): 아이 눈높이 도구 묶음, 도안(Starter) 위에 칠하기.
- [Krita Fill tool](https://docs.krita.org/en/reference_manual/tools/fill.html)·[Colorize mask](https://docs.krita.org/en/reference_manual/tools/colorize_mask.html): 허용 오차, 틈 메우기, 선 밑으로 확장해 흰 테두리 없애기.
- [Kleki](https://kleki.com/)·[Autodesk Sketchbook 도움말](https://help.autodesk.com/view/SKETPRO/ENU/): 웹 래스터 레이어 구성과 붓 설정.

위 도구의 SDK·에셋·계정을 쓰지 않았고, 화면 구성과 문구는 ourclass 기준으로 새로 만들었습니다.
