# 수중 미술관 이미지 키트

압축을 풀고 [에셋 카탈로그](index.html)를 열면 네 전시관의 이미지와 투명 시트를 볼 수 있습니다. [바닷속 관찰실](aquarium-preview.html)에서는 산호초·켈프 숲·심해·라군의 생물들이 실제 프레임으로 헤엄칩니다. 둘 다 로컬 브라우저에서 작동합니다.

## 작은 생물 꺼내 쓰기

- [서식지별 투명 PNG 시트](biodiversity/atlases/) 8장은 한 장에 6종씩, 가로 3칸 × 세로 2칸으로 배치했습니다. 어류 24종과 해초·산호·해면 등 24종입니다. [개별 WebP](biodiversity/specimens/)도 있습니다.
- [유영·추가 생물 시트](life/atlases/) 4장에는 거북·고래·가오리의 동작, 어류의 동작, 단독 어류, 붙박이 생물이 들어 있습니다. [개별 프레임](life/frames/)과 [재생 순서·속도·기준점](life/manifest.json)을 함께 제공합니다.
- PNG 옆의 같은 이름 JSON에 자를 위치가 있습니다. `rect = [x, y, width, height]`는 시트 왼쪽 위부터 잰 픽셀입니다. 투명 여백을 포함한 직사각형을 그대로 자르면 됩니다. 고정 격자의 전체 크기와 실제 생물 사각형은 각각 `cell`과 `rect`로 구분합니다.
- `anchor = [u, v]`는 잘라낸 이미지의 왼쪽 위를 원점으로 삼은 0–1 좌표입니다. 해초는 뿌리를, 어류는 몸통의 기준점을 고정합니다. 네 장으로 구성된 유영 동작은 각 생물의 `frames` 순서와 `fps`로 반복합니다.
- 카탈로그에서 생물을 열고 시트 위치를 확인하거나 투명 PNG로 저장할 수 있습니다. 심해·밝은 모래 양쪽에서 가장자리를 확인하려면 상세 화면의 배경을 바꾸세요.

## 공간 만들기

| 경로 | 수록 내용 |
| --- | --- |

| [scenes](scenes/) | 같은 구도에서 작품·캐릭터·유영 생물을 덜어낸 합성용 배경 12장 |

| [furnishings](furnishings/) | 각 전시관과 재질을 맞춘 의자·화병·작품 받침대 |

| [water](water/) | 굴절광, 빛줄기, 잔물결 높이, 부유 입자에 쓰는 회색조 이미지 |
| [공간 배치 데이터](layouts/exhibition.json) | 20개 전시실의 페이지 구성과 실당 작품 25점을 위한 벽·창·출입구 위치 |
| [shared](shared/) | 기존 관람 고양이와 전시 콘텐츠. 프로젝트에 있던 작품 이미지 145점과 20개 예시 전시의 작품 순서 |

공간을 둘러볼 때에는 바다 파노라마를 가장 뒤에 두고 생물 무리, 수조 유리, 창틀 순서로 배치합니다. 해초는 바닥에 뿌리를 고정하고 가까운 것과 먼 것의 크기·움직임을 다르게 주면 창 너머로 깊이가 생깁니다. 작품은 조명이 들어오는 전시벽 앞의 별도 평면에 놓습니다. 마감재를 입힌 벽과 출입구 옆면은 카메라가 옆으로 움직일 때 깊이를 만듭니다.

재질의 기본색은 sRGB, 거칠기와 노멀은 선형 데이터입니다. 노멀은 OpenGL 방향입니다. 노멀과 거칠기는 생성 원본의 표면 결에서 만든 보조 맵으로, 재질별 강도는 전시장 조명에서 조절할 수 있습니다. 합성용 배경에는 구도에 필요한 고정된 산호·바닥·조명이 들어 있습니다. 자유 이동용 장면은 건축 파트·재질·생물을 각각 배치해 구성합니다.

전체 파일의 ID·테마·크기·경로는 [통합 목록](manifest.json)에 있습니다. 재현용 생성 원본과 프롬프트도 포함했습니다. 작품 예시 중 137점은 이전에 생성한 이미지이고, 8점은 기존 과제 화면에서 추출한 예시입니다. 실제 수업에서는 동일한 작품 슬롯에 해당 반의 이미지를 연결하면 됩니다.

## 걸어서 관람하기 (walk.html)

`walk.html`을 Edge 또는 Chrome에서 열면 네 전시관을 걸어서 볼 수 있습니다. 파일 하나에 키트의 이미지가 모두 들어 있어 66MB이고, 처음 열 때 몇 초 걸립니다.

- 관마다 시안(`references`)을 기준으로 외관, 중앙 홀, 전시실을 따로 지었습니다.
  - 산호관: 구멍 뚫린 테라코타 지붕, 겹아치 입구, 곡면 수조
  - 켈프관: 리벳 박힌 청동 튜브 건물, 유리 볼트 홀, 유리 다리
  - 심해관: 절벽 위 원통 캡슐, 큰 원형 관측창, 유리 돔
  - 라군관: 진주빛 조개 지붕, 유리 터널, 물결 천장
- 전시실 20곳에 작품 25점씩 겁니다. 홀 다섯 번째 페이지의 **바다 아카이브** 방에는 그 관의 시안, 외관 입면도, 건축·생물 시트와 원본, 장면 원본 25점이 걸려 있습니다.
- 각 홀 남쪽 벽에는 외관 정면·측면·배면·지붕 그림과 생물 유영 시트·원본이 걸려 있습니다. 라군관에는 관람 고양이 시트와 걷기 16컷도 있습니다.
- 재질은 색·노멀·거칠기 맵을 모두 씁니다. 바닥 반사, 물빛, 수면, 부유물, 문틀 옆면, 유리 마감, 스포트 조명, 벤치, 의자, 화병, 받침대, 길 조명, 난간도 키트 그림으로 배치했습니다.
- 조작: W A S D·방향키로 걷고, 드래그나 Q·E로 둘러봅니다. 문으로 걸어 들어가거나 문·작품을 누르면 이동하거나 확대됩니다.
- 공간 치수와 작품 위치는 `layouts/exhibition.json`을 그대로 씁니다. 문틀·창·수조 그림의 뚫린 부분은 빌드할 때 그림의 투명 영역을 재서 벽에 실제 구멍으로 냅니다.
- 원본 코드는 `walk-src`에 있습니다. 수정한 뒤 아래 명령으로 다시 만듭니다. Python 3, Pillow, NumPy가 필요합니다.

```sh
python walk-src/build_walk.py
```
