# 작품 음성 설명

사진 업로드 후 작품 상세의 **아이 목소리 도슨트**에서 녹음합니다. 음성 파일 업로드는 지원하지 않습니다.

**내 이야기 녹음하기** → 원고 창에 원고를 쓰고(선택) → **녹음 시작** → 3·2·1 뒤 원고가 프롬프터처럼 큰 글씨로 천천히 넘어갑니다(글자 크기·넘김 속도 조절, 손으로 스크롤 가능). 원고 없이 바로 녹음할 수도 있습니다. 쓰던 원고는 기기에 임시 보관됩니다. 녹음을 마치면 미리 듣고, 원고가 작품 설명 글로 채워진 상태에서 고친 뒤 **작품에 올리기**를 누릅니다. 글을 비우면 목소리만 올라갑니다.

올린 녹음은 작품에 바로 보이며(선생님 확인 전 표시), 학생이 **글 고치기·다시 녹음하기(초안 교체)·삭제**를 할 수 있습니다. 최대 60초이며 브라우저가 16kHz 모노 WAV로 변환합니다. 교사가 승인하면 공개되고, 녹음과 글은 AI API를 사용하지 않습니다. 파일 저장·재생에는 기존 저장소와 전송 사용량이 발생합니다.

학생은 전시가 `open`이고 작품의 `studentId`가 본인과 일치할 때 음성을 추가할 수 있습니다. 작품 승인 전에도 가능하며, 이미 전시된 작품에도 추가할 수 있습니다. 교사가 대신 올린 사진도 실제 학생 연결이 필요합니다. `allowStudentUploads`는 사진 제출 설정으로, 음성 작성 권한과 별개입니다. `closed` 상태에서는 학생 녹음을 허용하지 않습니다.

공개된 음성이 있어도 새 초안을 만들 수 있습니다. 새 음성 승인 전까지 기존 음성을 유지하고, 승인 시 교체합니다. QR 방문자에게 재생하려면 전시 QR 공유와 `voice.publicAudio`가 모두 켜져 있어야 합니다.

AI 자동 캡션은 기본 비활성입니다. **별도 비용·범위에 대한 사용자 승인 이후에만** 운영자가 `VOICE_AI_TRANSCRIPTION_ENABLED=true`를 설정할 수 있습니다. 이때에도 담당 교사만 명시적인 **AI 자동 캡션 · 별도 API 비용** 버튼으로 요청할 수 있으며 학생의 직접 호출은 차단됩니다. `OPENAI_API_KEY`와 사용 가능한 `OPENAI_TRANSCRIBE_MODEL` 설정이 별도로 필요합니다. OpenAI 음성 전사 API 비용은 모델·음성 사용량·현재 요금 정책에 따르며, 호출 횟수 제한은 금액 예산이나 무료 사용량을 보장하지 않습니다. 저장·녹음 동작에는 자동 변환, 유료 대체 서비스, 자동 재시도가 없습니다.

로컬 검증: `node src/modules/voice-caption/run-tests.mjs`. 데이터베이스, 저장소, AI는 메모리 대역으로 검증하며 외부 서비스에 접속하지 않습니다.
