# 말놀이터 기본 문제은행 초안

`bank-v1`은 총 660문항으로 명세의 1단계 목표 수량을 채웠다. 넌센스·수수께끼·어휘는 각각 학년대별 60문항(각 180), 맞춤법은 학년대별 40문항(120)이다. 같은 문제의 말만 바꾸거나 학년대를 복사해 수를 채우지 않았고, 한 종류 안에서 정답이 겹치지 않는다.

2026-10-27 확장 때 수수께끼 `riddle-mid-020`은 정답이 틀려 있었다(얼음이 녹는 현상의 답이 `녹음`). 운영에 공개되기 전이라 같은 ID에서 문제와 정답을 바로잡았다. 공개 이후에는 아래 원칙대로 버전을 올린다.

이 목록은 개발 단계의 초안이며 현장 교사의 검수를 완료한 은행으로 간주하지 않는다. 학년대는 초기 난도 배정이고 교육과정의 공식 난도 판정이 아니다. 교사는 학급 기능을 켜기 전에 문항과 해설을 검토해야 한다. 특히 넌센스의 영어 소리 놀이, 한자 소리 놀이, 관용 표현은 학년과 학급에 따라 조정이 필요하다.

자동 검증은 총 문항 수, 중복 ID·문제 문장, 정답 및 보기 중복, 대표 정답 포함 여부, 필수 설명, 각 학년대의 최소 실시간 문제 수를 확인한다. 국어 표현의 자연스러움이나 수업 적합성은 자동 검증만으로 보장하지 않는다.

기존 행의 순서나 ID는 바꾸지 않는다. 새 문항은 각 학년대 목록 끝에 추가한다. 기존 문항의 정답이나 의미를 바꿀 때는 문항 버전을 올리고, 이미 발급한 회차의 문항 스냅샷은 그대로 보존한다.
