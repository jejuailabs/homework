# 말하기·읽기 스튜디오

교사 도구 모음(판서·자료)의 **말하기·읽기 스튜디오**다. 아이가 듣고, 따라 읽고, 말하고, 점검받는 흐름을 한 창에서 진행한다. 지금은 교사 도구로만 제공한다. 교실 시범 운영을 마친 뒤 같은 부품을 학생 개인 페이지로 옮기는 것이 목표다. 기획 배경은 [프리브리핑](../../../SPEECH_READING_STUDIO_PREBRIEF.md)에 있다.

## 화면

- **동화 서재**
  - 기본 책 3권: 전래 이야기를 새로 쓴 글.
  - 교사가 추가하는 PDF나 붙여 넣은 글.
    - PDF는 `pdfjs-dist`로 브라우저에서 열고 페이지 글을 꺼낸다.
    - 글이 없는 그림 페이지는 직접 입력하거나 AI로 읽게 한다.
  - 책을 추가할 때 출처, 이용 조건, 사용 확인을 반드시 받는다.
  - 책·PDF는 이 기기의 IndexedDB에만 저장한다. 서버에 올리거나 공개하지 않는다. AI 목소리를 쓰면 읽을 문장만 서버로 보내 음성을 만들고, 그 음성은 서버 공용 캐시와 이 기기에 남는다.
- **읽어 주기**
  - 문장 단위로 읽으며 읽는 문장을 강조한다.
  - 방법은 혼자 듣기, 한 문장씩 따라 읽기, 번갈아 읽기(AI 한 문장·아이 한 문장) 세 가지다.
  - 목소리는 기본이 기기 목소리(`speechSynthesis`, 무료)다. AI 목소리는 카드놀이와 같은 원어민 음성(Google Chirp 3 HD, `/api/tts`)이다. 같은 문장은 모든 반이 서버 캐시(`tts/v1/`)를 함께 쓰고, 이 기기에서도 IndexedDB에 한 번 더 저장한다. 빠르기는 기기에서 재생 속도로 바꾼다. 서버 음성이 꺼졌거나 실패하면 그 문장을 기기 목소리로 읽는다.
- **말하기 연습**
  - 활동은 따라 읽기, 주제 말하기, 말로 쓰기 세 가지다.
  - 녹음은 최대 2분이고, 16kHz 모노 WAV로 바꾼다.
  - 글로 옮기는 방법은 AI 전사, 기기 내부 음성 인식(`processLocally`), 교사 직접 입력 중에서 고른다.
  - 결과를 보기 전에 교사가 옮겨진 글을 확인하고 고친다.
- **기록·수준**
  - 학생별 최근 정확도와 추세, 자주 하는 오류, 다음 책 수준과 추천 책을 보여 준다.
  - 살펴볼 학생(정확도가 연속 하락하거나 80% 미만)과 학급의 AI 오인식 비율을 함께 보여 준다.

## 측정

| 항목 | 방법 | 위치 |
|---|---|---|
| 읽기 정확도 | 원문과 들은 말을 음절 단위로 레벤슈타인 정렬한 뒤 어절로 묶는다. 띄어쓰기·문장부호는 무시하고, 숫자는 읽는 소리로 바꾼다. 빠뜨림·바꿈·덧붙임을 표시하고, 같은 말을 다시 읽은 것은 감점하지 않는다 | `scoring.ts` |
| 분당 바르게 읽은 음절(CSPM) | 맞게 읽은 음절 ÷ 녹음 길이 | `scoring.ts` |
| 말 빠르기 | 음절 ÷ 실제 말한 시간(쉼 제외) | `scoring.ts` |
| 쉼·긴 쉼 | 녹음의 소리 크기로 0.35초 이상과 0.8초 이상 구간을 센다 | `audio.ts` |
| 목소리 크기 | 구절별 평균 크기의 고르기, 끝이 작아지는지, 전체가 작은지 | `audio.ts` |
| 억양 | 자기상관 피치 추정으로 높낮이 폭(반음)을 잰다. 2반음 미만이면 단조롭다고 본다 | `audio.ts` |
| 군말 | "음", "어", "그니까" 등이 어절 단위로 나온 횟수 | `scoring.ts` |
| AI 오인식 비율 | AI가 옮긴 글 중 교사가 고친 비율. 학생 점수가 아니다. 15% 이상이면 정확도를 참고용으로 안내한다 | `practice.tsx` |
| 책 수준 1~6 | 문장 길이·어절 길이·긴 낱말 비율로 추정하고 교사가 고칠 수 있다. 검증된 가독성 공식이 아니다 | `scoring.ts` |

읽기 수준 판단은 최근 5회를 기준으로 한다. 평균 95% 이상이면 한 단계 위, 90% 미만이면 한 단계 아래 책을 권하고, 그 사이는 같은 수준을 유지한다.

AI 전사 때 원문을 프롬프트로 넘기지 않는다. 넘기면 아이가 실제로 읽은 말 대신 읽어야 할 말을 듣게 되기 때문이다. 기본 모델 `gpt-transcribe`는 글만 돌려주므로 "확인 필요" 구간 표시가 없다. `SPEECH_TRANSCRIBE_MODEL=whisper-1`(2027-02-26 종료 예정)로 바꾸면 구간별 신뢰도(`avg_logprob`, `no_speech_prob`, `compression_ratio`)가 낮은 부분을 표시한다.

읽어 주기 AI 목소리는 2026-11-08부터 공용 서버 음성(`GOOGLE_TTS_ENABLED=true`, [CARDS_SPEC.md §37](../../../CARDS_SPEC.md))을 쓴다. 예전 OpenAI 목소리(`gpt-4o-mini-tts`, 기기 캐시만)는 `SPEECH_TTS_PROVIDER=openai`일 때만 남아 있고, 모델이 2027-01-06에 끝나므로 그때 `voice()` 경로와 함께 지운다. 기본값에서 예전 경로는 410 `VOICE_MOVED`를 돌려준다.

## 저장과 개인정보

- 서버는 녹음을 저장하지 않는다. 전사할 때만 OpenAI로 보내고 응답을 받은 뒤 버린다.
- `speechRecords`(Firestore)에는 다음만 저장한다. 학생 이름은 저장하지 않는다.
  - 교사·학급·학생 ID
  - 활동 종류, 책 제목·쪽, 수준
  - 확인한 글(3,000자 이하)
  - 측정값
  - 피드백
- 기록을 읽고 쓰고 지우는 것은 담당 교사만 할 수 있다. 클라이언트 Firestore 규칙은 기본 거부를 그대로 둔다.
- 말로 쓰기는 받아쓰기만 한다. 점수를 매기지 않고 서버에 저장하지 않는다.
- AI 피드백 프롬프트에는 이름을 넣지 않는다. 말하기 기술에만 한정하고, 외모·가정·감정은 언급하지 않도록 지시한다.

## AI와 비용

전사·피드백·페이지 글 읽기는 `SPEECH_AI_ENABLED=true`와 `OPENAI_API_KEY`가 모두 있어야 켜진다. AI 목소리는 `GOOGLE_TTS_ENABLED=true`로 따로 켠다. 꺼져 있으면 서재, 기기 목소리, 녹음, 기기 인식·직접 입력, 모든 측정, 기록 저장은 그대로 쓸 수 있고 별도 비용이 없다.

| 기능 | API 경로 | 기본 모델 | 비용이 드는 때 |
|---|---|---|---|
| 전사 | `POST /api/speech-studio/transcribe` | `gpt-transcribe` | 녹음 1건마다(분 단위) |
| 피드백 | `POST /api/speech-studio/feedback` | `gpt-6-luna` | 교사가 버튼을 누를 때마다 |
| 읽어 주기 목소리 | `POST /api/tts` (공용) | Google Chirp 3 HD (`GOOGLE_TTS_FAMILY=neural2`면 Neural2) | 모든 반을 통틀어 같은 문장 처음 1번. `SPEECH_AI_ENABLED`와 별개로 `GOOGLE_TTS_ENABLED`로 켠다 |
| 그림 페이지 글 읽기 | `POST /api/speech-studio/page-text` | `gpt-6-luna` | 교사가 버튼을 누를 때마다 |

- 모든 호출은 `runMeteredAi`의 교사·전체 한도를 따르고, 관리자 **API 사용량** 화면에 기능별로 집계된다.
- AI 호출은 교사 계정에서만 할 수 있다. 학생 페이지로 옮길 때는 학생 직접 호출 정책, 학급 한도, 법정대리인 동의를 먼저 정해야 한다.

- `node src/modules/speech-studio/run-tests.mjs`
  - 정렬·지표·수준 판단, 합성 음성의 쉼·억양·크기 분석
  - WAV 형식, 전사 응답 정리, 저장 기록 검증, 피드백 프롬프트
- 로컬 에뮬레이터 QA
  - 기록 저장·목록·삭제, 다른 학급·없는 학생 차단, AI 꺼짐 응답
  - 합성 마이크로 녹음·결과·저장, 마이크 차단·사용 중 안내
  - PDF 추가·글 추출·빈 페이지 안내, 따라 읽기 모드 진행
  - 휴대폰 너비 넘침 없음
