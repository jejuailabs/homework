# 실제 애월 길을 걷는 장난감 마을 샘플

2026-10-27. 이전 한 화면짜리 시안의 재질·캐릭터를 실제 OSM 도로 위에 옮겨, 카메라가 따라오는 연속 지도를 검증합니다.

## 반드시 지키는 지도 계약

- **실제 도로 중심선과 교차로 연결이 기준입니다.** 그림을 보기 좋게 만들기 위해 길을 생성하거나 옮기지 않습니다.
- **학교·행정관청·문화유산 등 장소의 위치를 유지합니다.** 이 샘플의 학교·우체국 핀은 OSM 좌표를 사용합니다. 데이터에 없는 역사·문화 장소를 임의 위치에 추가하지 않습니다. 해당 정보는 검증된 출처로 보완한 뒤 배치합니다.
- 장난감 이미지는 외관 표현입니다. 학교와 집의 실제 외관을 재현한 것은 아니며 나무·꽃·가로등·NPC는 시안용 장식/이야기입니다. 일반 집 그림의 기준점도 수집된 건물 위치에 둡니다.
- 이 버전은 북쪽이 위이고 **모든 거리를 동일하게 6px/m로 투영**합니다. 먼 구간의 거리 축소는 현재 적용하지 않았습니다. 향후 사용하더라도 길의 순서·연결·장소 관계를 보존하고 압축 구간을 구분해야 합니다.
- 미션 완료가 지도를 바꾸지 않습니다. 하나의 좌표계에서 길을 계속 걸으며, 귀환은 명시적인 별도 이동입니다.

## 실행 및 체험

프로젝트 루트에서:

```powershell
node src/modules/region-quest/scripts/serve-continuous.mjs
```

<http://127.0.0.1:8788>을 엽니다. 이전 한 화면 샘플은 별도 서버의 8787 포트에 그대로 있습니다. 서버는 시작 시 파일을 읽으므로 수정 후 재시작하고 브라우저를 새로고침합니다.

1. `길 따라 걷기`로 학교 앞 모모에게 갑니다.
2. 편지를 받고 길의 굽이까지 걷습니다. 화면이 끊기지 않고 캐릭터를 따라갑니다.
3. 지도 방향 단서를 확인하고 해안 도착점까지 이동해 편지를 전합니다.
4. 탐험 기록을 보고 학교로 귀환하거나 같은 맵을 더 둘러봅니다. `탐험 계속`은 귀환 전 위치로 복귀합니다.

직접 조작은 방향키/WASD/화면 방향 버튼, 길 클릭 이동, E 대화입니다. 미니맵은 실제 도로와 산책 경로, 현재 화면 범위를 표시합니다. 큰 지도에서 `원본 도로선 겹쳐보기`로 배경 그림과 실제 중심선을 비교할 수 있습니다. +/−는 화면 확대만 바꾸며 지형·좌표를 변경하지 않습니다.

진행은 이 브라우저의 `region-quest-aewol-continuous-v1`에만 저장합니다. 기존 샘플 저장과 분리되어 있습니다. 초기화는 페이지 안의 확인창으로 처리합니다.

## 범위와 검증 수준

- 애월초 인근 도로 → 길의 굽이 → 해안 도로 위 시범 도착점. **OSM 그래프 경로 420.92m**, 3762×3024 월드.
- 학교/우체국·주변 도로 33개·건물 49개·해안선을 기존 로컬 OSM 자료에서 추출합니다. [데이터 설명](data/README.md)과 원본 해시·수집일·출처를 보존했습니다.
- 해안 도착점은 실제 도로 위에 지정한 테스트 지점으로 공식 명소 이름이 아닙니다. 학교 출발점은 학교 근처의 도로 접점이며 실제 출입문 검증은 아직 하지 않았습니다.
- 편지 미션·모모는 허구입니다. 역사·문화 사실을 학습하는 정식 캠페인은 아직 없습니다.
- 화면에 보이는 도로 폭은 조작을 위해 단순화했습니다. 중심선 좌표는 그대로지만 좁게 나란한 길과 복잡한 교차로의 조작 폭은 향후 지형·보행 그래프를 함께 검수해야 합니다. 실제 보행 안내용이 아닙니다.
- 건물은 같은 카메라·빛·재질로 생성한 독립 이미지이며 높이가 있는 그림은 앞뒤 정렬합니다. 캐릭터를 가리는 앞쪽 건물은 반투명해집니다. 실제 좁은 해안 부지에서는 건물 그림을 줄이고 위치를 옮기지 않습니다.
- 이 작은 샘플은 지역 데이터를 한 번 읽고 보이는 이미지 위주로 그립니다. 대규모 지역의 청크 스트리밍은 아직 구현하지 않았습니다.

## 구현과 제작

| 파일 | 역할 |
| --- | --- |
| `data/aewol.json` | 원본 좌표에서 투영한 도로·장소·해안선과 provenance |
| `world.js` | 일정 축척 변환, 장식 배치, NPC·미션 지점 |
| `motion.js` | 도로 폭 안의 이동·A*·충돌·추적 카메라 |
| `game.js`, `game.html`, `game.css` | 렌더링, 미션, 미니맵, 귀환, 저장 |
| `assets/manifest.json` | 분리된 투명 이미지 12개 |
| `assets/generation.json` | Codex 내장 이미지 생성 프롬프트와 참조 기록 |

새 학교·우체국·집·소품은 **Codex 내장 이미지 생성**을 사용했습니다. 외부 유료 API 대체 경로는 사용하지 않았습니다. 생성 원본은 커밋하지 않고 알파 실루엣 추출·리사이즈한 WebP만 포함합니다. 기존 캐릭터와 모모 이미지 두 개를 재사용합니다.

`scripts/prepare-continuous-map.py`와 `scripts/prepare-continuous-assets.mjs`로 데이터와 에셋을 재현합니다. 사용한 OSM 원본은 Git 제외 `.cache/`에 있습니다. 런타임은 외부 API·DB·지도 타일을 요청하지 않으며 로컬 서버는 127.0.0.1에서만 실행됩니다.

```powershell
node src/modules/region-quest/tests/run-tests.mjs
```

자동 검증은 원본 도로 노드·연결 보존, 일정 축척, 실제 경로 왕복, 도로 밖 지름길·충돌 방지, 카메라 범위, 해안 채움, 서버 경계를 포함합니다.
