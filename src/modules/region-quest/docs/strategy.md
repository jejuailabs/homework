# 우리 학교 동네 탐험 RPG — 현장 니즈 조사와 구현 전략

작성일: 2026-10-27 · 대상: 초등 3~4학년 사회 '우리가 사는 곳' 영역 · 기반: 기존 `우리 동네 탐험` 도구 + `러닝킹` 게임 모듈 · 구현 지시서: [IMPLEMENTATION_BRIEF.md](../IMPLEMENTATION_BRIEF.md)

## 0. 한 줄 정의

**아이들이 학교를 중심으로 실제 길을 따라 우리 지역을 RPG처럼 걸어 다니며, 미션을 하나씩 해결하면서 지역의 문화·역사·인물·관광자원·삶·공공기관을 배우는 2D 픽셀 게임.** 향후에는 다른 지역으로 여행하고 내 학교로 돌아오며, 여러 지역의 이야기와 생활을 같은 방식으로 배웁니다. 같은 지역 데이터로 교사용 백지도·약도와 평가 자료도 함께 만듭니다.

핵심은 두 가지입니다.
- **정확한 실제 지역**: 실제 길과 실제 장소, 검수된 사실만 씁니다.
- **끊기지 않는 미션 흐름**: 이동 명령 → 안개가 걷힘 → 랜드마크 조사 → 배움 → 다음 이동 명령이 이어지며 지역 전체를 한 바퀴 돌게 합니다(6장).

## 1. 현장 교사의 페인포인트와 니즈 (조사 결과)

| # | 페인포인트 | 근거 | 이 제품이 답해야 할 니즈 |
|---|---|---|---|
| P1 | **지역화 수업 자료가 부족함.** 교사들은 3~4학년 지역화 단원 수업을 어려워하고, 자료 부족을 가장 시급한 문제로 꼽음 | 「2015 개정 사회과 교육과정 운영 실태와 개선 방안: 초등 3~4학년 중심」(KCI) | 우리 학교 주변 자료를 **자동으로 모아 주되 검수할 수 있게** 해야 함 |
| P2 | **교과서는 행정구역 단위라 아이들의 생활권과 맞지 않음.** 지역화 교과서의 위상이 바뀐 뒤 교사들이 자료집을 직접 만들고 있음 | 「초등 사회과 지역화 교과서 위상 변화 시기의 지역화 교육 실행 사례 연구」(한국지리환경교육학회지) | **학교 반경(생활권) 중심** 설계. 아이디어의 '학교 중심'이 연구 결과와 정확히 맞음 |
| P3 | **고장 모습을 알아볼 자료가 교과서·보조교과서 밖에서는 구하기 어려움.** 교사들은 구글 지도 캡처를 백지도에 옮겨 그리는 식으로 손수 만듦 | 「초등학교 3학년을 위한 지역화 학습 시스템 개발 및 적용」(한국정보교육학회), 공부하자.com 단원 안내 | 캡처·트레이싱 작업을 **원클릭 백지도·약도 생성**으로 대체 |
| P4 | **현장체험학습이 급격히 위축됨.** 초등교사 96.2%가 체험학습에 부정적(법적 책임 49.8%, 민원 37.0%). 서울 실시율 86%(2023) → 31%(2026) | MBC·중앙이코노미뉴스·오마이뉴스·한국교육신문 보도(초등교사노조 설문) | 직접 나가지 않아도 되는 **가상 고장 답사**, 또는 실제 답사 전 **사전 답사** |
| P5 | **디지털 지도 도구는 조작을 익히는 데 시간이 듦**(구글 지도 수업에서 기능 적응에 약 10분) | 쌤동네 구글 지도 수업 사례 | 조작은 **방향키와 클릭만**. 차시 안에 바로 몰입할 수 있어야 함 |
| P6 | **백지도는 수준별로 정보량을 달리 써야 함**(흑백 단순 백지도는 위치 쓰기와 형성평가용) | 「초등 사회과 학습을 위한 백지도의 개발과 활용」, 지학사 백지도 안내 | 같은 지역을 **정보량이 다른 여러 장**으로 출력(완성 지도 → 반 백지도 → 완전 백지도) |
| P7 | **에듀테크 개인정보 검증 부담이 교사에게 넘어옴**(학습지원 소프트웨어 수백 종을 교사가 확인) | 헤럴드경제 2026-02 보도 | **학생 위치·사진 수집 없음**, 기존 학급 계정 안에서 동작. 별도 가입 없음 |
| P8 | **자료 정확성.** 틀린 지역 정보를 가르치면 신뢰가 무너짐(교사 지역 지식의 편차) | 「사회과 지역 교과서의 활용 실태」(교사의 지역 이해 제고 제안) | 사실마다 **출처·기준일**, 교사 검수 전에는 학생에게 노출하지 않음 |
| P9 | **교사 업무 부담.** 한국 초등교사 42.8%가 학생 관리·변화 대응에서 높은 어려움을 겪음. 디지털 기술은 주로 수업 보조에 쓰임 | KEDI TALIS 2024 분석(한국교육신문) | **준비 10분 이내**를 목표로. 진도·결과가 학습지와 평가로 자동 정리되어야 함 |

### 교육과정 연결점 (2022 개정, 3~4학년군 '우리가 사는 곳')
- **[4사01-01]** 주변 여러 장소에서의 경험과 느낌을 다양한 방식으로 표현하고 장소감을 나눔 → 게임 속 **장소 일기·도감 카드**
- **[4사01-02]** 주변 장소를 살펴보고 더 살기 좋은 곳으로 만드는 방안을 탐색 → **"동네 고치기" 제안 퀘스트**
- 고장의 공공기관, 옛이야기와 인물, 문화유산과 관련된 성취기준은 NCIC 원문에서 코드와 문구를 확인한 뒤 퀘스트 태그로 매핑합니다(이번 조사에서는 문구를 직접 확인하지 못함).

### 조사 한계와 보완 방법
- 인디스쿨 같은 교사 커뮤니티 글은 로그인이 필요해 검색으로 확인하지 못했습니다. 논문과 보도 위주의 근거입니다.
- 게임·메타버스를 우리 고장 단원에 적용한 **효과 검증 연구는 찾지 못했습니다.** 기장군(메타버스 도로명주소 교육), 유성구(VR 스탬프투어) 같은 운영 사례만 있습니다. 시장은 비어 있지만 효과는 직접 증명해야 합니다.
- → **1단계에서 3~4학년 담임 5~8명과 인터뷰**: 실제 차시 흐름, 현재 쓰는 자료, 백지도 사용 방식, 가장 시간이 드는 작업을 확인합니다.

## 3. 핵심 설계 원칙

1. **데이터 한 벌, 출력 여러 개.** 지역 팩 하나에서 백지도·약도·게임 맵·학습지가 모두 파생됩니다. 교사의 검수도 한 번이면 됩니다.
2. **좌표가 진실.** 게임 타일맵은 실제 좌표에서 투영한 결과입니다. 북쪽이 위이고, 축척과 도로 연결(교차로)이 유지됩니다. 귀여움은 그 위에 입히는 스킨입니다.
3. **정확성은 등급으로 관리.** `자동 수집 → AI 요약 → 교사 검수 완료`. 학생 화면에는 검수 완료된 사실만 나갑니다.
4. **학생 데이터는 최소한으로.** GPS, 실사진, 실명 위치를 쓰지 않습니다. 교실에서 하는 가상 탐험입니다.
5. **40분 차시 단위.** 한 차시 = 한 구역 또는 한 퀘스트 묶음. 이어하기가 기본입니다.

## 4. 데이터 아키텍처

### 4.1 출처별 역할

| 데이터 | 1차 출처 | 비고·확인할 점 |
|---|---|---|
| 학교 위치 | 공공데이터포털 **전국초중등학교위치표준데이터**(한국교육시설안전원, 위경도 포함, 월 단위 병합) | 학교 검색 → 중심점 자동 설정 |
| 도로·보행로·건물 외곽·하천 | **OpenStreetMap**(현재 사용 중) | **ODbL**: 렌더링한 이미지는 출처 표시만 하면 되지만, 가공한 *데이터베이스*를 공개 배포하면 동일 라이선스 공유 의무가 생깁니다. 지역 팩을 교사 간에 공유할 때 유의 |
| 배경지도·교육용 백지도(보조) | **국토지리정보원 영상지도·배경지도 API**(공공누리 1유형 출처표시, 무료, *교육용 백지도* 레이어 포함), 수치지도 다운로드(NGII·국가공간정보유통) | **공간정보관리법상 국외 반출 제한** 때문에 해외 리전 서버(Vercel 기본 리전)에서 호출할 수 없다는 언급이 있음 → 서울 리전(icn1) 고정 또는 클라이언트 직접 호출 가능 여부를 확인해야 함 |
| 문화유산 | **국가유산청 문화재마스터위치정보 API**(공공데이터포털, 이용허락 제한 없음), 지정유산 지도 다운로드 | 지정 등급·명칭을 공식 명칭으로 표시 |
| 관광지 | **한국관광공사 TourAPI**(위치기반 조회) | 이용 조건과 이미지 저작권은 직접 확인 필요(이번 조사에서 미확인) |
| 행정관청·공공기관 | OSM `townhall/police/fire_station/post_office/library` + 행정표준코드·기관 주소 | 주민센터는 명칭과 위치 변경이 잦으므로 기준일을 표기 |
| 역사·인물·옛이야기 | **화이트리스트 출처만 사용**: 한국민족문화대백과, 디지털향토문화전자대전, 국가유산포털, 시·군 시사(市史)·교육청 지역화 자료 | AI는 요약만 하고 문장마다 출처를 붙임. 인물 평가처럼 논쟁적인 서술은 교사 검수를 필수로 함 |
| **스팟 정보(1차)** | **구글 Places API**: 이름, 주소, 분류, 소개, `place_id` | 약관상 구글 데이터는 구글이 아닌 지도와 함께 쓸 수 없고, 위경도는 30일까지만 캐시 가능 → **DB에는 `place_id`·주소만 저장하고, 좌표는 행정안전부 도로명주소 좌표 API로 변환**(주소 없는 곳은 교사 핀). 교사 검토 화면은 구글 지도 임베드로 미리보기 |
| ❌ 카카오·네이버 | 사용하지 않음 | 구글로 스팟 수집을 단일화. 로컬 API 결과의 저장·타사 지도 표시 제약 문의가 반복됨 |

### 4.2 지역 팩 데이터 모델 (기존 `NeighborhoodPack` 확장안)

```ts
type RegionPack = {
  version: 2;
  school: {code: string; name: string; lat: number; lon: number};
  extent: {radiusM: number; polygon?: [number, number][]};    // 반경 또는 교사가 그린 생활권 경계
  projection: {originLat: number; originLon: number; metersPerTile: number}; // 게임과 지도가 공유하는 좌표계
  network: {nodes: Node[]; edges: Edge[]};                    // 보행 가능한 도로 그래프(교차로 위상 유지)
  areas: Area[];                                              // 건물 외곽, 공원, 하천, 논밭
  places: Place[];
  sourceLog: {source: string; url: string; retrievedAt: string; license: string}[];
};
type Place = {
  id: string; kind: 'office' | 'heritage' | 'tour' | 'nature' | 'market' | 'school' | 'story';
  name: string; lat: number; lon: number;
  facts: {text: string; sourceUrl: string; retrievedAt: string; status: 'auto' | 'draft' | 'verified'; verifiedBy?: string}[];
  curriculum: string[];          // 예: ['4사01-01']
  gameRole?: 'npc' | 'landmark' | 'collectible' | 'quest-hub';
  level: 1 | 2 | 3;              // 백지도 정보량 단계와 난이도
};
```

## 5. 지도 생성 파이프라인

```
학교 검색 → 생활권 범위 지정 → 수집(OSM·공공 API)
   → 정규화(이름 한글화, 중복 병합, 분류)
   → 도로 그래프 생성(교차로 노드 분할, 보행로·횡단보도 유지)
   → 교사 검수 큐(장소 포함/제외, 사실 승인, 누락 장소 직접 추가)
   → ┬ 벡터 약도 렌더러 → 스타일 N종 (SVG/PDF)
     └ 타일 변환기   → 픽셀 RPG 맵 (JSON 타일맵 + 충돌맵)
```

### 5.1 약도·백지도 스타일 (같은 벡터, 다른 스킨)
| 스타일 | 용도 |
|---|---|
| 교과서형 컬러 약도 | 수업 도입용 판서 |
| 단계별 백지도 L1/L2/L3 | 완성 지도 → 이름 빈칸 → 길만 남은 지도. 수준별 학습과 형성평가 |
| 그림지도(크레용·수채 느낌) | 3학년 그림지도 그리기 예시 |
| 픽셀 아트 | 게임 화면과 같은 모습. "게임에서 본 그 길" 연결 |
| 기호 지도 | 범례·방위표·축척 막대 연습 |

→ 단순화 정도(`simplifyMapLine`의 epsilon), 도로 위계별 굵기, 라벨 밀도만 바꿔도 대부분 구현됩니다. 모든 출력에 방위표, 축척 막대, 출처, 기준일을 자동으로 넣습니다.

### 5.2 픽셀 타일맵 변환 (길을 정확하게 만드는 법)
- **투영**: 학교를 원점으로 하는 로컬 미터 좌표(등장방형 근사, 반경 2km 안에서는 오차가 무시할 수준) → 1타일 = 4~6m 권장. 반경 1km면 약 400×400 타일이므로 청크 단위로 로드합니다.
- **도로**: 그래프 엣지를 타일에 래스터화하되 위계별로 폭을 정합니다(대로 3타일, 골목 1타일). **교차로 노드는 반드시 걸을 수 있는 타일로 강제**해 길이 끊기지 않게 합니다. 변환 후 BFS로 학교에서 모든 장소에 도달할 수 있는지 자동 검사합니다.
- **건물**: OSM 외곽선은 타일로 채우고, 랜드마크는 종류별 귀여운 스프라이트(시청, 소방서, 도서관, 정자, 오름 등)로 교체합니다. 외곽선이 없는 지역은 블록 안을 일반 주택 타일로 절차적으로 채웁니다.
- **자연**: 하천, 바다, 논밭, 공원은 영역 타일로 그립니다. 제주라면 돌담, 귤밭, 오름 같은 지역 타일셋 확장이 차별점이 됩니다.
- **학교 앞 안전**: 어린이보호구역과 횡단보도를 게임 안의 "건너기 규칙" 미니 상호작용으로 활용합니다(안전 교육 연계).

## 6. 게임 설계 (최종)

> **한 문장 정의**: 아이는 RPG 미션을 따라 우리 지역의 구역을 하나씩 걸어 들어갑니다. 구역에 도착하면 안개가 걷히고, 그 구역의 핵심 랜드마크를 조사하며 **문화·역사·인물·관광자원·삶·공공기관**을 배웁니다. 미션을 마치면 바로 다음 구역으로 가라는 명령을 받습니다. 이렇게 흐름이 끊기지 않은 채 지역 전체를 한 바퀴 돌게 됩니다.
>
> 배우는 대상은 **지역 그 자체**입니다. 지도와 길 안내는 그것을 찾아가는 수단입니다.

### 6.1 무엇을 배우나 — 6개 분야 + 교사 스팟

| 분야 | 다루는 것 | 애월초 예시(검수 필요) | 주요 데이터 출처 |
|---|---|---|---|
| **역사** | 유적, 옛 지명, 사건, 옛날과 오늘날 | 애월진성(현재 애월초 담장), 애월환해장성 | 국가유산 API, 향토문화전자대전, 교사 |
| **인물** | 지역 출신·관련 인물과 그 기록 | 장한철과 『표해록』, 생가와 기적비 | 한국민족문화대백과, 향토문화전자대전, 교사 |
| **문화** | 전통 생활문화, 민속, 축제, 건축 | 밭담, 초가, 정낭, 마을 행사 | 향토문화전자대전, 지자체, 교사 |
| **관광자원** | 자연경관, 명소, 길(올레 등) | 한담 해안 산책로, 곽지해변, 오름, 올레 15·16코스 | TourAPI, OSM, 지자체 |
| **삶** | 사람들이 하는 일과 생활, 산업 | 애월항 어업, 해녀, 귤 농사, 시장 | 교사, 지자체 자료, OSM(항구·시장) |
| **공공기관** | 주민을 위해 일하는 곳과 그 역할 | 읍사무소, 우체국, 파출소, 보건지소, 도서관, 119센터 | OSM, 공공데이터, 교사 |

**교사 수동 스팟 입력**
- 지도를 클릭하면 스팟이 추가되고, 6개 분야 중 하나를 고릅니다.
- 입력 항목: 이름, 설명(사실 카드), 출처 URL, 교사가 직접 찍은 사진(선택), 핵심 랜드마크 여부, 숨은 스팟 여부.
- 자동 수집이 비어 있는 곳(애월에서는 문화유산 전부)을 교사가 채우는 통로입니다. 교사가 입력한 사실은 입력과 동시에 `verified`로 처리합니다(교사 본인 검수).

### 6.2 지역 구조: 구역(Zone)과 핵심 랜드마크

- **지역 팩 = 여러 구역**입니다. 구역은 *안개 단위*이자 *메인 미션 1개의 무대*입니다.
- 구역마다 구성은 다음과 같습니다.
  - **핵심 랜드마크** 1곳(반드시 조사)
  - **보조 스팟** 0~4곳(길 위의 발견, 서브 미션)
  - **숨은 스팟** 0~2곳(안개 속 "?")
- **자동 구역 나누기**
  - 핵심 랜드마크 후보를 중심으로 반경 150~300m씩 묶습니다.
  - 경계는 큰길, 해안, 하천 같은 자연 경계에 맞춥니다.
  - 교사는 경계를 드래그하거나, 구역을 합치거나 나눌 수 있습니다.
- **애월초 구역 예시**(좌표·사실 검수 전 가안)

| 순서 | 구역 | 핵심 랜드마크 | 분야 |
|---|---|---|---|
| 1 | 학교와 옛 성 | 애월진성 성담(학교 담장) | 역사 |
| 2 | 마을 한가운데 | 애월우체국(약 285m) | 공공기관 |
| 3 | 애월 포구 | 애월항(약 505m) | 삶 |
| 4 | 바다를 지킨 담 | 애월환해장성 | 역사·문화 |
| 5 | 한담 해안 | 장한철 생가·표해록 기적비 | 인물·관광자원 |
| 6 | 읍내 큰길 | 애월읍사무소·도서관 | 공공기관 |
| 7 | 밭과 오름 | 밭담·귤밭·오름 전망 | 문화·관광자원·삶 |
| 피날레 | 학교로 귀환 | 지역 이야기책 완성 | 전체 |

### 6.3 핵심 루프 — 미션 한 바퀴

```
① 이동 명령 → ② 길 따라 이동(길 위의 발견) → ③ 구역 진입: 안개가 걷힘
   → ④ 핵심 랜드마크 조사 → ⑤ 배움 카드·이야기 획득 → ⑥ 미션 완료·보상
   → ⑦ 다음 이동 명령 → ① …  (모든 구역 완료 → 피날레 → 향후 다음 지역으로)
```

| 단계 | 화면에서 일어나는 일 |
|---|---|
| ① 이동 명령 | 안내자 NPC가 *어디로, 왜* 가야 하는지 말합니다. 예: "포구의 해녀 할망이 너를 찾고 있어! 학교에서 북동쪽이야." 목표가 화면 위에 고정됩니다. |
| ② 이동 | 발자국 길 표시와 방위 화살표가 안내합니다(교사가 끌 수 있음). 이동 중 보조 스팟에서 작은 발견(10~20초짜리 짧은 상호작용)이 일어나서 걷는 시간이 비지 않습니다. |
| ③ 구역 진입 | 구역 경계를 넘으면 안개가 걷히는 연출과 함께 **구역 이름 카드**("애월 포구")가 나타나고, 구역 안의 길과 건물이 드러납니다. |
| ④ 랜드마크 조사 | 네 가지 행동을 조합합니다. **만나기**(NPC·인물 대화), **살펴보기**(장면 속 단서 2~3개 클릭), **확인하기**(검수된 사실로 만든 문제 1~2개), **기록하기**(장소 사진기와 한 줄 느낌). |
| ⑤ 배움 | 분야 아이콘이 붙은 **배움 카드**(검수 사실 2~3줄 + 출처)가 도감에 들어가고, 이야기 조각을 얻습니다. |
| ⑥ 완료 | 구역 도장, 분야 경험치, 이야기 장면이 하나 열립니다. |
| ⑦ 다음 명령 | 완료 대화의 마지막 줄이 곧 다음 명령입니다. 대화창이 닫히는 순간 새 목표가 표시됩니다. |

**피날레**: 마지막 구역의 필수 미션을 마친 뒤 지역 거점에서 마무리 대화를 하면 "우리 지역 이야기책"(도감 + 장소 기록)이 완성됩니다. 첫 지역의 거점은 내 학교이고, 방문 지역에는 별도의 만남 장소가 있습니다. 지역 탐험가 배지를 받고, 지역 연결이 켜져 있으면 다음 여행의 초대장이 열립니다(6.7). 도중에 귀환 버튼으로 거점에 돌아온 것은 피날레 완료로 처리하지 않습니다.

### 6.4 흐름이 끊기지 않게 하는 규칙 (가장 중요)

1. **목표가 없는 순간을 만들지 않습니다.** 화면에는 항상 현재 메인 목표 1개가 고정되어 있습니다. 엔진은 "목표 없는 상태"를 오류로 검사합니다.
2. **완료와 다음 명령은 한 대화 안에서 이어집니다.** 메뉴 전환이나 로딩 화면을 끼우지 않습니다.
3. **이동은 1~2분을 넘기지 않습니다.** 게임 속 이동 속도로 다음 목적지까지 2분이 넘으면 중간 경유 스팟을 자동으로 넣습니다.
4. **막힘은 단계적으로 풉니다.** 30초 동안 경로를 벗어나면 화살표를 강조하고, 2분 동안 진행이 없으면 안내자가 힌트를 줍니다. 3분이 지나면 "같이 가 줄까?"(자동 이동)를 제안합니다.
5. **실패가 없습니다.** 문제를 틀리면 단서를 다시 보여 주고 재도전하게 합니다. 진행은 항상 앞으로 갑니다.
6. **차시가 바뀌어도 이어집니다.** 해넘이가 되면 미션·대화·체험의 중간 상태와 귀환 전 위치를 저장하고 거점으로 돌아옵니다. 다음 시간에는 30초짜리 "지난 이야기" 회상 뒤에 "탐험 계속"으로 같은 목표에서 재개합니다. 거점에 있는 동안에도 중단한 목표와 이어가기 버튼을 보여 줍니다.
7. **빈 구간이 없습니다.** 교사가 일부 미션만 설정해도 나머지는 자동 미션이 채웁니다. 저장할 때 "끊긴 연결, 도달할 수 없는 구역, 미승인 사실 사용"이 0인지 검사합니다.
8. **곁가지가 메인을 막지 않습니다.** 보조·숨은 스팟은 선택입니다. 들렀다 오면 메인 목표가 그대로 남아 있습니다.
9. **이야기로 연결합니다.** 구역과 구역 사이에는 연결 문장을 넣습니다. 예: "성을 지키던 사람들은 무엇을 먹고 살았을까? 포구로 가 보자."

### 6.5 미션 만들기 — 기본은 자동, 원하면 교사가 편집

**자동 캠페인 생성(기본값)**
1. 구역마다 핵심 랜드마크를 고릅니다. 기준은 분야 균형, 검수된 사실 수, 교사 지정 여부입니다.
2. 순서를 정합니다.
   - 학교 구역에서 시작합니다.
   - 이야기 연결(같은 시대, 인물, 주제)과 이동 거리 최소화를 함께 고려합니다.
   - 같은 분야가 세 번 연속 나오지 않게 합니다.
   - 끝은 학교 또는 피날레 장소입니다.
3. 랜드마크 분야와 종류에 맞는 **미션 템플릿**을 적용합니다(아래 표).
4. 구역 사이 연결 대사를 생성합니다. **검수된 사실만** 사용합니다.
5. 검사합니다: 모든 구역 도달 가능, 연결 끊김 없음, 미승인 사실 0.

| 분야 | 기본 미션 템플릿 예 |
|---|---|
| 역사 | 옛 물건·단서 찾기 → 옛날과 오늘 비교 장면 → 이야기 조각 |
| 인물 | 인물(상상해서 그린 모습) 만나기 → 그가 남긴 것(기록·건물) 살펴보기 → 인물 카드 |
| 문화 | 전통 물건·건축의 쓰임 맞히기 → 생활 장면 체험(정낭 걸기 등) |
| 관광자원 | 경관 전망 지점 찾기 → 장소 사진기 → 소개 카드 만들기 |
| 삶 | 일하는 사람 돕기(그물 정리, 귤 따기 등 짧은 체험) → 하는 일 알아보기 |
| 공공기관 | 주민 부탁 해결(편지 배달, 잃어버린 물건, 민원 접수) → 기관이 하는 일 카드 |
| 교사 스팟 | 교사가 고른 템플릿 + 교사가 쓴 설명·질문 |

**교사 미션 편집기**
- **순서 바꾸기**: 구역과 미션을 드래그로 재배치합니다.
- **고치기**: 명령 대사, 조사 문장, 문제와 정답, 힌트를 직접 수정합니다.
- **새로 만들기**: 템플릿 선택 → 스팟 지정 → 문장과 질문 입력. 중간 미션을 끼워 넣을 수 있습니다.
- **스팟 추가**: 6.1의 수동 스팟 입력과 같은 기능입니다.
- **차시 설정**: 이번 시간에 열 구역과 시작 미션을 지정합니다.
- 자동으로 만든 것은 "자동", 교사가 고친 것은 "선생님" 배지가 붙습니다. 자동 생성을 다시 실행해도 **교사 수정분은 보존**됩니다(덮어쓰기 층을 따로 저장).

**대화형 미션의 기본 품질**

NPC 대화는 의뢰를 받고 단서를 묻고 발견한 것을 돌려주는 실제 미션 행동입니다. 모든 메인 미션에는 목적이 있는 대화, 학생의 선택 또는 조사·체험, 그 행동에 대한 NPC의 반응, 다음 목표로 이어지는 마무리를 넣습니다. 같은 문제를 연속해서 읽고 정답만 고르는 구성은 피하고 6분야 템플릿별 행동을 다르게 만듭니다.

| 대화 장치 | 학생의 행동과 반응 |
|---|---|
| 의뢰와 선택 | 주민의 부탁을 듣고 "더 물어볼래요 / 해 볼게요"처럼 2~3개 선택지로 대화를 진행합니다. 질문 순서는 달라도 필수 배움에 도달합니다. |
| 단서·물건 제시 | 조사한 그림 단서나 이야기 아이템을 골라 NPC에게 보여 줍니다. 부족하면 어디서 살펴볼지 힌트를 줍니다. |
| 짧은 체험 | 대화에서 맡은 편지 배달·그물 정리·전통 물건 사용 등을 수행하고 돌아오면 주민의 표정과 대사가 바뀝니다. |
| 분기와 합류 | 궁금한 것을 골라 묻거나 해결 방법을 선택합니다. 분기마다 사실·반응은 달라질 수 있지만 필수 목표로 다시 합류하며 막다른 길은 없습니다. |
| 재방문 | 의뢰 전·진행 중·완료 후 인사와 행동을 달리하고, 다시 대화해 배움 카드를 복습할 수 있습니다. 완료 보상은 중복 지급하지 않습니다. |
| 다음 지역의 연결 | 향후에는 초대장·소개 편지 같은 이야기 소품으로 새 지역 주민을 만납니다. 두 지역의 검수된 사실을 비교하는 선택 활동을 넣습니다. |

- 대사 한 번은 2~3줄이며 초상·표정·장면과 함께 읽습니다. 대화 기록 다시 보기, 읽어 주기, 키보드 선택을 지원합니다. 연출을 건너뛰어도 필요한 선택·조사·체험은 완료되어야 합니다.
- **사실과 허구의 역할을 구분합니다.** 지역·인물·생활에 관한 문장과 문제에는 검수된 사실 ID를 붙입니다. 안내자, 의뢰 상황, 반응은 창작 연출로 표시하며 실제 역사 인물의 발언이나 실제 사건으로 주장하지 않습니다. 과거 모습·인물 초상은 "상상해서 그린 모습"으로 표기합니다.
- 학생이 만나는 대화는 교사가 미리 확인한 분기 데이터로 재생합니다. AI는 제작 단계에서 초안을 돕고, 학생의 선택마다 새로운 외부 AI 호출을 필요로 하지 않습니다.
- 선택한 분기·제시한 단서·체험 상태를 저장합니다. 귀환·새로고침 후에도 같은 단계에서 이어지며 아이템 소비나 보상이 중복되지 않습니다. 모든 분기가 필수 학습과 다음 목표로 합류하는지는 시뮬레이터로 검사합니다.

### 6.6 RPG 요소

| 요소 | 내용 |
|---|---|
| 내 캐릭터 | 기존 12캐릭터의 픽셀 버전 |
| 안내자 | 지역 세계관 동료. 예: 제주는 바람 정령 '지움이'(지역 이야기를 날려 버린 장난꾸러기가 함께 되찾으러 다님) |
| 퀘스트 로그 | 메인(구역 순서)과 서브(보조·숨은 스팟) |
| 도감 | 6분야 배움 카드 |
| 성장 | **분야별 탐험가 등급**. 예: "애월 역사 탐험가 Lv.3". 분야 카드를 모으면 오름 |
| 도장 여권 | 구역 도장 → 지역 완주 도장 → (향후) 여러 지역 여권 |
| 이야기 조각 | 모으면 지역 이야기 장면(옛 애월 포구 등)이 열림 |
| 이야기 아이템 | 옛 편지, 표해록 조각, 포구 그물 등 미션 속 소품 |
| 숨은 스팟 | 안개 속 "?" — 용천수, 옛 비석 같은 발견의 재미 |
| 주민과의 대화 | 표정·선택지·단서 제시·체험 결과에 따른 반응, 완료 후 재방문 대사 |
| 탐험 거점 | 첫 지역은 내 학교, 방문 지역은 만남 장소. 귀환해서 정리하고 중단한 탐험을 계속함 |
| 지도와 여행 | 현재 지역 미니맵, 향후 여러 지역을 고르는 월드맵과 발견한 거점 간 워프 |

**지도 읽기는 따로 가르치지 않고 자연스럽게 익히게 합니다.** 미니맵에는 처음부터 방위표와 지도 기호가 있습니다. 안내자는 "북동쪽"처럼 방위로 말합니다. 지도 읽기는 성장 시스템이 아니라 이동을 돕는 도구입니다.

**이미지로 만드는 RPG 경험**

이미지 생성은 지형 타일에 그치지 않고 대화·조사·발견·여행 장면 전체에 활용합니다. 먼저 미션별 장면표를 만들고, 필요한 이미지 키·표정·동작·등장 조건을 적어 빠진 연출을 찾습니다. 같은 주민·장소는 참조 시트와 팔레트를 공유해 장면이 바뀌어도 같은 인물과 동네로 보이게 합니다.

| 화면 | 필요한 이미지 묶음 |
|---|---|
| 걷는 세계 | 지역별 지형·건물·생활 소품·랜드마크, 캐릭터 이동·일하는 주민 동작 |
| 대화 | 주민별 기본·기쁨·궁금함·걱정 4표정 초상, 말풍선·선택지 패널, 제시할 물건 그림. 놀람·생각·감사 등 추가 표정은 장면표에 따라 확장 |
| 조사와 체험 | 확대 조사 장면, 클릭할 단서별 이미지, 조사 전후 상태, 체험 소품과 완료 반응 |
| 이야기와 보상 | 지역 소개·전환·완주 장면, 과거 모습 비교 그림, 배움 카드·도장·칭호·이야기책 삽화 |
| 귀환과 여행 | 거점 외형·귀환 표식·여행 연출, 향후 지역 대표 그림·관문·발견/잠김/선택 상태의 지도 아이콘 |

- 이름·대사·선택지·출처·지도 라벨은 런타임에서 글자로 표시합니다. 생성 이미지에 글자나 클릭 영역을 맡기지 않습니다. 단서에는 텍스트 설명과 키보드 포커스를 붙입니다.
- 실제 도로·위치·미니맵 윤곽은 지역 데이터로 렌더링하고, 생성 이미지는 그 위의 표현과 장식에 사용합니다. 이미지 때문에 장소 위치나 길 연결이 바뀌지 않습니다.
- 장면과 초상은 필요할 때 불러옵니다. 기본 아틀라스와 지역·미션별 이미지 묶음을 나누고, 저사양 모드에서도 필수 단서와 미션 조작이 유지되도록 합니다.
- **최대한 활용한다는 요구는 제작 범위에 반영합니다.** 실제 생성 전에는 서비스·모델·장수·재시도 한도·예상 비용을 묶음별로 설명하고 별도 승인받습니다. 기존 요청 수 추정은 확정 예산이 아니며, 승인 전에는 장면표·프롬프트·후처리 규격을 준비합니다.

### 6.7 귀환, 지역 여행과 지도 (확장을 염두에 둔 구조)

**첫 출시부터 제공하는 귀환과 이어가기**
- **내 학교**는 탐험을 시작한 본거지입니다. **현재 지역 거점**은 지금 탐험하는 팩의 안전한 만남 장소입니다. 첫 지역에서는 둘이 같고, 다른 지역을 방문하면 서로 다릅니다.
- 학생은 미션 중에도 "거점으로 귀환"할 수 있습니다. 현재 위치와 별도로 귀환 전의 미션·대화·체험 단계, 이야기 아이템, 안전한 재개 위치를 체크포인트에 저장합니다. 귀환은 비용·아이템 소모·보상·학습 완료 판정이 없는 이동입니다.
- 거점에서는 도감·이야기책을 보고 "탐험 계속"을 누르면 중단했던 단계로 돌아갑니다. 반복 귀환으로 체크포인트를 거점 위치로 덮어쓰지 않습니다. 미완료 조사나 문제, 필수 NPC 대화를 귀환으로 건너뛸 수 없습니다.
- 수업 해넘이와 교사 일괄 귀환도 같은 저장 규칙을 씁니다. 학생 조작을 먼저 멈추고 저장 결과를 확인한 뒤 이동합니다. 저장 실패 시 원래 진행을 보존하고 다시 시도할 수 있게 하며, 저장에 성공했다고 표시하지 않습니다.

**향후 지역 간 여행**
- **월드 그래프**: 지역 팩 하나가 노드이고, **관문 스팟**(버스정류장·항구·고개 등)으로 연결합니다. 방문 지역도 6분야의 주민·조사·체험·보상 루프를 갖추며 고유한 이야기와 그림을 제공합니다.
- 첫 방문은 관문의 소개 대화와 도착 지역 주민의 안내를 거칩니다. 이전 지역의 초대장이나 이야기 소품이 다음 지역의 배움으로 이어집니다. 완주 후에는 지역 이야기책과 여권 도장을 모으고 "우리 지역과 무엇이 같고 다를까?"를 기록할 수 있습니다.
- **열리는 조건**: 교사가 허용한 지역 중 캠페인 완료로 열린 연결 또는 교사가 직접 연 연결만 이용합니다. 완주나 방문 기록 자체는 다른 교사의 팩을 볼 권한이 되지 않습니다.
- **진도**: 지역별 캠페인 버전·체크포인트·도감·안개는 각각 보존하고, 탐험가 등급·여권은 학급 내 학생의 공통 프로필에 누적합니다. 같은 미션·카드의 재방문 보상은 한 번만 집계합니다.
- 타지역에서도 "이 지역 거점으로"와 "내 학교로"를 구분해 표시합니다. 내 학교로 돌아와도 방문 지역의 이어가기 위치는 남습니다. 내 학교 팩이 더 이상 허용되지 않으면 현재 허용된 지역 거점에 머물며 교사에게 안내합니다.

**현재 지역 미니맵과 향후 월드맵·워프**
- **현재 지역 미니맵**은 처음부터 제공합니다. 방위·내 캐릭터·열린 구역·목표·거점·관문을 보여 주고, 선택하면 큰 지역 지도를 엽니다. 미니맵의 캐릭터 위치는 게임 좌표이며 실제 GPS를 쓰지 않습니다.
- **월드맵**에서는 교사가 공개한 지역의 대표 그림, 방문/미방문, 완주, 잠금 이유를 보여 줍니다. 지역을 선택하면 그 지역의 미니맵과 이어갈 목표, 이미 발견한 이동 지점을 볼 수 있습니다. 미방문 지역의 숨은 장소·문제 정답은 공개하지 않습니다.
- **워프**는 직접 발견한 안전 지점 중 현재 수업에서 허용된 곳으로만 가능합니다. 처음 가는 지역은 관문 진입과 소개 미션을 거치고, 이후의 재방문에 워프를 사용합니다. 교사 귀환과 중단 지점 이어가기는 별도 동작으로 처리합니다.
- 워프는 위치만 바꾸며 조사·대화·체험의 완료 조건은 그대로 검사합니다. 도착만 필요한 단계가 정상 진행될 수는 있지만, 미완료 학습·닫힌 구역을 통째로 건너뛰거나 안개와 보상을 일괄 해제하지 않습니다.
- 이동 전 서버가 대상 팩 배정, 공개 상태, 게시 버전, 구역 개방, 지점 해금과 도착 지점의 안전성을 다시 확인합니다. 저장과 대상 로딩을 확인한 뒤 활성 지역을 전환합니다. 실패하면 원래 지역·체크포인트를 유지합니다. 교사 일시정지·종료 상태에서는 학생 워프를 막습니다.

**지금 확보할 구조와 이후 공개 범위**
- 전역 고유 팩 ID, 원점과 위경도, 거점·관문·워프 지점 ID, 지역별 진도와 귀환 전 체크포인트를 지금 설계합니다. 모든 이동은 같은 저장·검증 절차를 사용합니다.
- 첫 출시는 현재 지역 귀환·이어가기·기본 미니맵·대화형 미션을 완성합니다. 여러 지역을 고르는 월드맵, 지역별 미니맵 목록, 지역 간 이동·워프는 시범 학급 검증 후 별도 기능으로 엽니다.
- 학교 주변 → 읍·면·동 → 시·군 → 도 단위로 넓힙니다. 이웃 학교 팩과의 연결은 교사 간 공유 정책과 데이터 이용 조건을 확인한 뒤 제공합니다.

### 6.8 수업 리듬과 교사 통제

| 시간 | 흐름 | 장치 |
|---|---|---|
| 0~5분 | 교사 도입(오늘 갈 구역 소개) | 교사 화면의 함께 탐험 모드 |
| 5~30분 | 미션 진행 | 이동 명령 → 조사 → 다음 명령의 연속 |
| 30분 | 게임 속 해넘이 | 진행 중 미션과 체크포인트를 저장하고 현재 지역 거점으로 귀환 |
| 30~40분 | 정리 | 오늘 얻은 배움 카드, 장소 기록, 학급 진행률 공유 |

- 교사 버튼: 모두 멈춤, 모두 거점으로 귀환, 구역 열기/닫기, 오늘 시작 미션 지정, 힌트 보내기. 향후 여러 지역 수업에서는 귀환 목적지를 현재 지역 거점 또는 내 학교로 명시하고, 방문 지역과 워프 허용을 설정합니다.
- 교사 화면에는 아이의 실시간 위치가 아니라 *현재 미션, 완료 구역 수, 막힘 여부*만 보입니다.

### 6.9 장소감과 "동네 고치기" (선택 미션 유형)

- **장소 사진기** → [4사01-01]: 랜드마크 조사의 "기록하기"로 들어갑니다. 장면 캡처와 감정 스티커, 한 줄 느낌을 남기고 학급 갤러리에 공유합니다(교사 승인).
- **동네 고치기** → [4사01-02]: 교사가 지정한 지점에서만 나옵니다. 불편한 점을 고르고 해결 아이디어를 쓰면 반 전체 투표로 이어집니다(기존 `class-poll`).

### 6.10 평가 근거 자동 수집

| 근거 | 게임에서 남는 것 |
|---|---|
| 분야별 지역 지식 | 6분야 배움 카드 수, 확인 문제 정답률(분야별) |
| 장소감 표현 | 장소 기록(사진기, 한 줄 느낌) |
| 살기 좋은 곳 방안 | 동네 고치기 아이디어, 투표 |
| 지역 전체 이해 | 완주한 구역 수, 지역 이야기책 |
| 지도 표현(부록) | 내가 다녀온 지역 지도 출력물. 백지도 L1~L3는 교사 출력용으로 별도 제공 |

→ 학급 리포트에 분야별·성취기준별로 묶어서 보여 주고, 개인 "우리 지역 이야기책" PDF로 출력합니다.

### 6.11 아이 안전·접근성 원칙

- 실시간 GPS 없음, 아이 사진 없음(교사 스팟 사진은 교사 소유 자료), 자유 채팅 없음, 개인 주택·상호 라벨 없음
- 인물은 "상상해서 그린 모습"으로 표기하고, 특정 얼굴을 주장하지 않습니다.
- 대사는 한 번에 2~3줄, 3학년 어휘, 읽어 주기, 어려운 말 사전
- 키보드·터치·클릭 이동, 색만으로 구분하지 않기, 순위표 대신 학급 공동 진행률

### 6.12 교사 페인포인트 해소 점검표

| 페인포인트 | 해소 장치 | 교사가 직접 하는 일 |
|---|---|---|
| P1 지역화 자료 부족 | 자동 수집 + 6분야 자동 캠페인(6.5) | 사실 검수, 필요하면 스팟 추가 |
| P2 행정구역 ≠ 생활권 | 학교 중심 구역 나누기(6.2) | 구역 경계 조정 |
| P3 자료를 손으로 만듦 | 미션·대사·문제·카드 자동 생성, 백지도 자동 출력 | 고칠 곳만 수정 |
| P4 체험학습 위축 | 지역 전체를 가상으로 한 바퀴 + 사전 답사 모드 | 구역 순서 선택 |
| P5 도구 조작 학습 시간 | 방향키·터치·클릭 이동, 첫 화면에서 바로 첫 명령 | 없음 |
| P6 수준별 자료 | 백지도 L1~L3, 미션 문제 난이도 조절 | 단계 선택 |
| P7 개인정보 검증 부담 | GPS·사진·채팅 없음, 기존 학급 계정 | 안내 1장 제출 |
| P8 자료 정확성 | 검수된 사실만 사용, 출처 표시, 지어낸 역사 대사 금지 | 승인 클릭 |
| P9 수업 통제 부담 | 끊기지 않는 흐름(6.4), 해넘이, 멈춤·귀환, 평가 근거 자동 정리 | 버튼 몇 번 |

## 7. 교사 워크플로 (목표: 준비 10분)

1. 학교명 검색 → 자동 중심 설정 → 반경 또는 생활권 경계 조정 (1분)
2. 자동 수집 결과 확인: 장소 목록에 *자동/초안/검수완료* 배지 (3분)
3. 사실 카드 검수: 출처 링크를 보며 승인, 수정, 삭제. 누락 장소는 지도를 클릭해 6분야 중 하나로 추가 (4분)
4. 자동 생성된 구역과 미션 순서 확인. 필요하면 드래그로 순서를 바꾸고 미션 문장을 수정 (1분, 선택)
5. 출력: 게임 링크 또는 QR, 백지도 PDF(L1~L3), 약도 스타일 (1분)
6. 같은 학교·시군 교사가 만든 **검수 완료 팩을 불러오기** → 두 번째 교사부터는 1분

## 8. 기술 구현 방향

- **게임 런타임**: 러닝킹처럼 **iframe으로 격리된 Canvas2D 타일 렌더러**를 권장합니다. 타일맵, 스프라이트, 충돌, 카메라 정도면 엔진 없이도 충분하고 번들이 가볍습니다. 저사양 크롬북과 태블릿에서 60fps를 목표로 합니다. 기능이 커지면 Phaser 같은 엔진 도입을 검토합니다.
- **저장**: 지역 팩 메타데이터는 Firestore, 큰 지오메트리와 타일맵 JSON은 Storage에 두고 버전·기준일로 관리합니다. 학생 진도는 기존 journey-storage 패턴을 따르되 학급 단위로 서버에 동기화합니다. 현재 위치·귀환 전 체크포인트·지역별 미션과 대화 상태를 구분하고, 재시도에도 아이템과 보상이 중복되지 않게 합니다.
- **수집 서버**: 기존 `/api/neighborhood/map` 확장. Overpass 미러 정책(현재 private.coffee)은 그대로 유지하고, 결과를 캐시해 같은 학교를 다시 조회할 때 재사용합니다. 국토지리정보원 API는 서울 리전 함수 또는 클라이언트 호출로 분리합니다.
- **에셋**: 픽셀 타일셋·캐릭터·표정 초상·조사 장면·이야기 삽화를 하나의 아트 디렉션으로 통일합니다. 기존 캐릭터·아바타와 톤을 맞추고, 기본 아틀라스와 지역·미션별 이미지 묶음을 분리해 필요한 장면만 로드합니다. 구체 규격과 생성 승인 범위는 구현 지시서 6장을 따릅니다.
- **접근성**: 키보드와 터치 모두 지원, 큰 글씨 대사, 색각 이상을 고려한 지도 팔레트.

## 9. 단계별 로드맵

| 단계 | 기간(가늠) | 산출물 | 완료 기준 |
|---|---|---|---|
| **0. 검증** | 2주 | 교사 인터뷰 5~8명, 시범 지역 3곳(제주시 도심 / 읍·면 농어촌 / 수도권 아파트 단지) 데이터 품질 점검 | 지역마다 OSM 도로·건물 커버리지 리포트, 핵심 차시 흐름 확정 |
| **1. 지역 팩 v2** | 3주 | 학교 검색, 생활권 경계, 공공 API 수집기, 검수 큐 | 교사 한 명이 10분 안에 팩을 검수 완료 |
| **2. 약도 스타일 엔진** | 2주 | 백지도 L1~L3, 교과서형, 그림지도, 픽셀 스타일 PDF·SVG | 교사가 실제 수업에 인쇄해서 사용 |
| **3. 미션 루프 MVP** | 4주(기존 가늠, 대화·아트 범위 확정 후 재산정) | 타일 변환기, 이동·충돌, 구역 안개, 목표 HUD·기본 미니맵, 대화 분기·조사·체험, 배움 카드, 자동 캠페인, 거점 귀환·이어가기 | 애월 7구역을 목표 공백 없이 완주, 대화·체험 도중 귀환·재개 후 진도와 보상 일치, 한 학급 시범 수업 |
| **4. 교사 편집·수업 연결** | 3주 | 스팟·구역·미션 편집기, 수업 통제, 학급 진행률, 이야기책 PDF, 분야별 리포트 | 교사가 미션을 고쳐 한 단원(6~8차시)을 게임으로 운영 |
| **5. 확산** | 이후 | 교사 간 팩 공유(같은 시군), 지역 타일셋 확장, 사전 답사 모드 | 두 번째 교사의 준비 시간 1분 이내 |
| **6. 지역 간 여행** | 시범 검증 후 | 월드맵·지역별 미니맵, 관문 이동, 발견 지점 워프, 내 학교 귀환, 누적 여권 | 두 지역에서 대화·조사·귀환·재방문을 끝까지 진행, 권한 변경·저장/로딩 실패에도 진도 보존 |
