# 애월초등학교 기준 OSM 데이터 품질 측정 리포트

측정일: 2026-10-27 · 중심: 애월초등학교(OSM way 371530161, 33.46512, 126.32235) · 데이터: OpenStreetMap API v0.6 bbox 추출(반경 2km 사각형) · © OpenStreetMap contributors, ODbL 1.0

> 앱이 쓰는 Overpass 미러(`overpass.private.coffee`)는 측정 PC에서 시간 초과로 응답하지 않았습니다. `overpass-api.de`는 TLS 오류가 났습니다. 그래서 OSM 공식 API로 같은 범위를 받아 측정했습니다. 운영 서버(Vercel)에서도 같은 문제가 있는지는 확인하지 않았습니다.

## 1. 요약 판정

| 영역 | 판정 | 한 줄 |
|---|---|---|
| 도로·보행로 | 🟢 충분 | 반경 1km 안 61km, 모든 길이 학교와 하나로 연결 |
| 해안선·항구 | 🟢 충분 | 애월항 방파제까지 정확해서 바다·육지 구분이 가능 |
| 공공기관 | 🟡 대부분 있음 | 우체국·파출소·보건지소·읍사무소·도서관·중학교·고등학교 있음. 119센터는 OSM에 없음(실제 존재 여부 확인 필요) |
| 건물 | 🔴 부족 | 반경 1km 안 건물 외곽선 92동뿐. 마을 대부분이 빈 땅으로 보임 |
| 토지 이용(밭·과수원) | 🔴 거의 없음 | 타일맵 면적의 62.8%가 "아무 정보 없는 땅" |
| 문화유산·역사 | 🔴 없음 | 애월진성, 애월환해장성, 장한철 생가·표해록 기적비, 한담해안산책로 모두 OSM에 없음 |

**결론: OSM은 게임의 '길 뼈대'로는 충분합니다. 하지만 수업에서 가장 중요한 '이야기(역사·인물·문화유산)'는 OSM에 없습니다.** 그래서 국가유산 공공데이터와 교사 추가 기능이 선택이 아니라 필수입니다. 건물과 땅의 모습은 공공 건물 데이터나 절차적 채우기로 보강해야 귀여운 마을처럼 보입니다.

## 4. 게임 타일맵 변환 시험 (5m/타일, 2km 사각형, 400×400 타일)

| 항목 | 결과 |
|---|---|
| 타일 구성 | 빈 땅 62.8% · 바다 27.8% · 도로 5.9% · 해안선 2.0% · 녹지 0.8% · 건물 0.7% |
| 걷기 가능 타일 중 학교에서 도달 가능 | 100% |
| 이름 있는 장소 29곳(교사 추가 가정 포함) 중 도달 가능 | 29곳(100%) |

### 변환에서 발견한 함정 (파이프라인 필수 규칙)
1. **대각선 도로 끊김**: 1칸짜리 선을 그냥 래스터화하면 대각선 칸끼리 모서리만 닿습니다. 그래서 상하좌우로 걷는 RPG에서는 **도달률이 0%**였습니다. → 대각선 이동마다 모서리 칸을 함께 칠하는 4방향 연결 래스터화로 고친 뒤 100%가 됐습니다.
2. **바다가 육지로 번짐**: 도로가 해안선 칸을 덮어 쓰면서 틈이 생겼고, 바다 채우기가 육지까지 번졌습니다(바다 92.7%). → 해안선을 별도 장벽 마스크로 유지하자 27.8%로 정상화됐습니다.
3. **장소 표시 순서**: 장소 칸을 경로 계산 중에 표시하면 같은 칸의 다른 장소가 "도달 불가"로 잘못 나옵니다. → 경로 계산을 모두 끝낸 뒤 표시합니다.

## 5. 다음 조치
- 국가유산청 위치 API와 디지털제주문화대전으로 애월진성·환해장성·장한철 관련 장소의 좌표를 확정합니다(지금은 근사 좌표로 시험).
- 국토교통부 건물 공간정보로 건물 외곽선을 보강할 수 있는지, 이용 조건과 함께 확인합니다.
- 빈 땅 62.8%는 지역 타일셋 절차 생성(밭담, 귤밭, 초가)으로 채우는 프로토타입을 만듭니다.
- 운영 서버에서 Overpass 미러 응답을 점검합니다. 실패하면 캐시와 자체 추출본으로 전환합니다.
- 같은 측정을 도심 학교 1곳, 수도권 아파트 단지 학교 1곳에서 반복해 비교합니다.
